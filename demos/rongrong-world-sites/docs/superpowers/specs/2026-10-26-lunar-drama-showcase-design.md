## Approach and boundary

Use a separate visitor-only showcase channel. Existing `CreativeScene` intentionally displays static templates, and its sole creature admission reuses pig care for poop-pal. Extending that path would conflate model identity, commerce and four-legged animal mechanics. Extending the seven-species authority would also need unrelated lifecycle admission. A dedicated actor registry retains each original model identity and actual authored skeletal motion while remaining outside farms, inventories, sales, breeding, exchanging and gifts.

The source is the user's supplied generated GLB; compression/rig/motion authoring are derivative work and must be labeled as such. The UI can show verified source-art/GLB/action provenance only when those references actually arrive. It must not pretend there is live prompt-to-model generation. Friend identity remains an honest theme example.

## Experience

On lunar entry, load only admitted showcase models, at most two concurrently. Other visits and the home startup fetch no showcase GLBs. Five actual identities occupy reviewed safe points; replace the older six-slot placeholder count with the exact five delivered identities, never fabricate a sixth. Each clickable character exposes a small labeled action row, greeting and temporary carry where the actual profile permits. A short automatically scheduled performance yields immediately to user action. The chicken has actual dribble and shooting clips, with ball contact/release driven by its clip time and actual hand anchor. The deterministic low-poly hoop and court do not imply imported AIGC assets.

All action clocks are local active time, paused while hidden, offscreen or modal/visit suspended. Resume must not fast-forward a shot or auto performance. Picking up stops performance and hides/resets the ball; setting down safely returns the actor to idle. Leaving/switching/disposal invalidates every pending load and action. These actors are never `MinimalAnimal`, never carry a pig species alias, and have no save/outbox/HTTP/economy path.

## Resources and safety

A compiled immutable per-character catalog binds unique id, name, original-source identity, final URL/bytes/SHA256, normalized size and physical envelope, real clip names/durations, named support/head/hand anchors, and explicit capabilities. Bytes must be fetched, SHA-checked and parsed; no external GLB references or private author paths. Skin/bone/animation/grounding and transitions are measured on actual output. Unknown/failed candidates are not selectable/interactable and are never represented by ordinary animal fallback.

Resource admission follows the existing exact public-origin, server-verified signed-in/named-demo bootstrap and opaque issued resource contexts. This is a static-resource scope, not a login/ownership token. A query name, plain object, arbitrary URL, sample id or imported save never issues it. It grants no commerce authority. Model inspection does not become admission.

Keep the old seven providers and all source receipts untouched. No schema, database migration, auth/namespace, formal economy, or dependency changes are planned.
