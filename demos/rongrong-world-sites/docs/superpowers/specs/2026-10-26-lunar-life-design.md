# Lunar companions: living movement and real sample growth

The user rejected stationary, once-per-visit performers. The five distinct user-provided characters must walk with actual articulated clips, explore, pause, look/interact, and perform again at varied intervals. The later request adds visibly giant chicken/floral actors and real age/care growth, not cosmetic size buttons.

## Approach
Keep the existing visitor-only identity and verified resource registry. Add a bounded, deterministic local life controller: rest → interest → safe path/turn/walk → settle → recurring authored gesture. Reuse the ordinary animal's pure 60s/120s age-to-scale curve, but keep the sample's age/care state in memory and label it honestly. Alternatives rejected: a faster one-shot loop remains a statue; translating an idle/bobbing whole mesh is sliding, not walking; importing these characters as pig aliases would corrupt identity/economy.

Each walk contract is `{clip,duration,strideMeters}` at the existing normalized adult scale. Growth multiplies the entire actor and stride/body/support geometry exactly once. Phase follows actual traveled distance; no lateral root travel is baked into the clip. Frame deltas are bounded and hidden/carried/user-action time does not accumulate a catch-up burst. Manual stop causes a meaningful rest, not permanent disablement of life.

Path planning uses full circle clearance on owned dry supported land, static obstacles and dynamic actor/player bounds; each step rechecks before moving. Heading and speed are continuous. No root correction/teleport is permitted. Chicken walks back to a reserved shooting point and aligns before basketball; a ball is never spawned while it wanders.

Growth uses real monotone active age with stage/scale reporting and cooldown-limited care, smoothly applied only with enough reserved clearance. Chicken and floral begin as giant adults; others visibly progress from baby/juvenile. This remains sample raising, reset on departure, not formal ownership. Existing canonical custom animals and economy are untouched.

## Verification
TDD covers repeated actions and real displacement beyond 60 seconds, phase/distance, safe blockage/replanning, staggered rest, manual interruption, carried/hidden pause, real age/care progression, giant footprints, court alignment and return. Actual final GLBs must prove walk deformation/contact, full transition envelope, and growth-scaled court/hand/ball/LX checks. Final CPU World/UI checks cover home zero writes/resources/camera, fake scope rejection, keyboard focus and mobile HUD. No browser/GPU acceptance claim.
