Obtain exact five names, original/final hashes, bytes, preview, geometry/texture budget, skin/bone graph and real clip list. Keep raw source/private provenance out of public. Write no fake catalog rows.
2. **Pure contracts and local timeline (TDD).** Separate actor identity from `Species`/`MinimalAnimal`. Exact allowed actions from per-actor descriptors; stable active-time clock, idle/action/blend/carry state, deterministic auto schedule, cancellation and epoch invalidation. 3. **Scoped on-demand actual-byte library (TDD).** Bind from existing trusted bootstrap to issued static-resource context; compiled manifest only. Fetch/hash/parse actual GLB, reject external URI/private extras/invalid clips/skin; two-worker budget, bounded timeout/AbortSignal, explicit retry, unique instance bones/materials and idempotent resource release. Never fetch at ordinary home startup or non-lunar visit.

Tests for total geometry budget, supported floor bounds, owned clearance, camera projection, continuous dribble/release/flight, stop resets, disposal once. No independent timer.
5. **Actor scene and World hooks.** Own per-visit scene; normalized actual templates with mixer; all actions in place. `WorldTarget` gains a distinct showcase kind, never animal/creative alias. Tick from World active delta only, picking actual visible skin, carry support uses measured clearance and dry landing/collision checks. World disposal stops and releases instances before its generic tree disposal.
6. **Visitor UI.** Distinct DIY character name/action icons; truthful provenance; short auto-performance and click action. Carry/greet enabled only for measured capabilities. Failed loading has explicit retry/lock, no substitute. Home camera, commands, retained resources and account outbox unchanged.
7. **Actual assets and evidence.** After Library arrival/rig export, review images, independently hash/parse/measure, enter only passed records, exercise all five in actual World. If an asset blocks, isolate it and report exact reason rather than weakening tests. Replace five reserved positions only after actual readiness, remove the obsolete sixth placeholder without fabricating an actor.
8. **Final combined review/release input.** Full tests/DOM/type/full lint/build, real source/asset pins and protected-path hashes; independent review of isolation/action/physics/late loading. Official fresh source helper preparation and immutable archive only; root handles native publication.
