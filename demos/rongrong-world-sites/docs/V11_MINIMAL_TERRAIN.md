# V11 · 轻松地块牧场

本轮是独立的轻养成原型，不把 V9 的食堂、粮食链、防御强度或邻接星级换一层皮。默认入口改为 V11；`?legacy` 保留 V9，`?harvest` / `?convoy` 保持原入口。

## 操作闭环
点动物/土地 → LX 走近 → 小气泡选择动作 → 看到行为/地形变化。
领到动物礼物 → 留在家里展示，或出售 → 开辟新地 / 改造地形 / 迎接新幼崽。

- 初始 4×4 = 16 格已开辟土地；当前原型可见 10×10 格。
- 外围是压暗但可辨认的溪流、丘陵、草地、林地，不是海洋或纯黑迷雾。
- 只能开辟四边相邻的地块；溪流地块保留可行走的岸边。
- 地形作用体现在动物喝水、吃草、休息和精力恢复；不会叠加金币倍数，不会因缺某地形导致死亡。
- 初始免费水盆/休息处，不必先学习生产建筑。
- 礼物可以出售或展示，出售后图鉴仍保留；动物不出售。
- 刀盾狗默认守护；两只狼只是轻捣乱，无物资损失、动物死亡或离线袭击。

## 原型数值，不是上线平衡结论
| 项目 | 演示规则 |
| --- | --- |
| 初始金币 | 80 |
| 开辟 | 每格 40 |
| 改造 | 首次开辟后开放，每次 20 |
| 新幼崽 | 80，最多 8 只 |
| 礼物 | 第一份 10 秒，此后全牧场每 120 秒一份；不随动物数量加速 |
| 出售 | 每份 20；每第 10 份为稀有纪念物，不加价 |
| 待收上限 | 14 份，离线按时间补发到上限 |
| 小狼演示 | 首次 45 秒，此后约 4 分钟；18 秒自行结束，可帮忙缩短 |

正式版应另测每日短访问节奏。以上快节奏用于试操作，不代表需要每两分钟上线。

## 架构与存档
- `src/minimal/model.ts`：确定性状态、四邻寻路、消费、礼物、照顾与离线补发。
- `src/minimal/World.ts`：Three.js 正交相机、柔和陆地、分身移动、动物动作和两狼演出。
- `src/minimal/MinimalApp.tsx`：场景气泡、背包、领养与轻量帮助。
- 新存档键 `dreamina-minimal-farm-v1`，仅当前浏览器本机保存；不复用或迁移 V9 服务端存档。
- 本轮新模式没有接入 AI 视频、在线访友或跨设备同步，不以按钮或文案假装已接通。

## 参考边界
参考产品 `island/dreamina-manor-v0.1` 的现场点击、走近再行动、正交镜头、淡色材质与简洁抽屉。镜头参考宽度 10.4、偏移 [9,13.8,18]，不把旧美术场景测试的透视相机误认为最新庄园参数。
不复制海洋边界、钓鱼生产链、五档投入物、容量计算或轻量 uid 身份方案。

## 验收边界
自动化覆盖地块、经济、连续行走、自然饮水、无溪流时水盆兜底、持久化、React 场景动作交互和旧版回归。不能把单元测试当成真实手机触控、帧率或视觉效果验收。本轮 dot 环境的 Chromium WebGL 启动受执行环境限制，实际画面验收需另行完成。
