# 五种动物牧场上手指南

先孵出一位伙伴，再慢慢逛。动物详情只在你主动点选时出现，不用一直盯着面板。

## 一分钟开始玩

领取金币 → 去小店买蛋 → 放到亮起的空地 → 等蛋准备好 → 点「孵开看看」→ 点动物认识它

1. 点「领取 120 金币」，再点「去商店，买第一颗蛋」。LX 会走到柜台前。
2. 点「买一颗 · 30」，选一块亮起的空地。LX 走近后把蛋放好；蛋留在蛋袋里不会开始孵化。
3. 第一颗放下的蛋等 10 秒，之后的蛋等 15 秒。准备好后点蛋，再点「孵开看看」，不会自动孵开。
4. 新伙伴落地后，点它查看名字、性别、亲密和成长阶段。孵化提示不会替你打开动物详情。

## 记住这几个操作

| 你想做什么 | 怎么操作 |
| --- | --- |
| 看动物详情 | 轻点动物，打开一张小卡；点另一只就切换 |
| 让 LX 走路 | 普通模式下轻点已开辟的空地，同时收起当前小卡 |
| 换个角度看 | 鼠标拖拽或单指拖动旋转；双指捏合或滚轮缩放 |
| 取消这次互动 | 点卡片右上角 ×，或点空地；走近时也可以点「取消」 |

看详情不会自动打招呼或举起动物。深池塘不能穿过，走岸边即可。

## 五种伙伴慢慢长大

绵羊 · 小猪 · 奶牛 · 兔子 · 小鸭

新伙伴从孵出开始计时：幼崽 → 60 秒成为少年 → 120 秒成年。每只都有自己的体型，刷新不会重新抽物种、性别或成长尺寸。旧版伙伴沿用原有成长记录。

动物会自己散步、吃草、喝水和休息，不需要逐只手动喂食。想和它互动时，点卡里的「打招呼」：LX 会走近挥手，伙伴回应并增加亲密。它和自动吃草、喝水是不同的动作。

想养下一代时，让同种、异性且已成年的两位伙伴靠近；符合条件时，小卡会出现「碰碰鼻尖」。有机会留下对应物种的蛋，不保证每次成功；每只每天只能尝试一次，全园每天最多成功得到一颗。按 UTC+8 的自然日更新，刷新不能重试。

## 举起来 放下来 或送去新家

点动物 →「举起来」→ LX 走近后举到头顶 → 带着它走动

- 想留下：走到空一点的地方，点「放下」。系统会找附近安全的干地；如果太挤，会提示你换个位置，不会强行放进水里或其他动物身上。
- 想出售：点「带去商店出售」，到柜台后查看价格，再点「出售 · … 金币」。只到商店不会自动出售；确认出售后，这只动物会离开牧场。
- 一次只能举一只，先放下再抱另一位伙伴。

## 模型和存档

- 动物模型加载失败时，打开右上角「设置与说明」，点「重试动物模型」。重试不用重新开园。
- 进度保存在当前浏览器的本机数据中，没有自动跨设备同步。换浏览器、换设备或换访问入口，不会自动带上另一处的进度。
- 同一浏览器、同一网址只保留一个牧场标签页，多个页面目前会相互覆盖进度。若已开多个，保留进度正确的那页，先关闭其他页，等保存后再刷新。
- 不要随意清理网站数据；无痕窗口关闭后也可能不再保留进度。看到「暂时无法保存」时，先不要关闭页面。
