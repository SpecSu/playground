# 绒绒农场 V25 · Sites 运行版


当前默认入口是萌蛋牧场：买蛋、放置孵化、养成、照料、繁育和出售。设置中的“动作预览”提供 25 种临时 Blender 动物模型、332 个真实骨骼动作；临时预览模型不会替换正在养的动物。V25 将设置、商店、图鉴、许愿池与地形等面板改为紧凑图形卡片，细则放进“?”帮助；人物步速调为 0.5 格/秒，保留岸边鞋底安全距离，未开放功能仍如实标注。此前 V24 修复动作预览启动失败时的部分资源清理，保留原错误提示和重试入口，不改变隐藏页面的帧调度。此前 V23 把动作预览猫的躯干花纹改为贴合表面的薄层；此前 V22 优化了动作预览中狗和熊的腿部连接，保留骨架、绑定和动作；实际牧场动物未替换。此前 V21 同步了拖动松手保护、斜向靠近、繁育新蛋保存保护，以及人物池塘岸边距离保护。

动态页面和 API 由 Worker 检查 Sites 注入的 ChatGPT 登录身份。未登录页面跳转到平台登录，API 返回 401；所有已登录访客使用同一入口，不在应用中硬编码个人白名单。站点外围权限仍由发布配置决定，代码构建成功不等于公开分享已经开启。JS、图片和 GLB 是公开静态素材，不含用户存档。

默认牧场与图鉴保存在当前浏览器本机，旧版协作模式使用浏览器设备 Cookie 和 D1。这里没有改成账号同步，也没有迁移、清空或合并旧存档；同一浏览器切换账号不会自动隔离本机存档。Mac 和 Sites 的存档相互独立。

下方保留旧版模式与服务端适配说明。

## 本轮内容

- LX 分身、3 秒喂养动作与手部 IK、幼崽吸奶和成年进食。
- 两只狼错峰从外围进入，真实避让、守护者选择时危险冻结。
- 真实登台、眺望、预警与安全下台，狗/奶蛙 +2、猫 +4 视距，仅台顶生效。
- 图标化背包，品质、数量、分类和用途，真实出售、合成、粮食与装备命令。
- 三套真实同源 API：`/api/estate`、`/api/convoy`、`/api/harvest`。

## 存档和身份

Sites 使用 Cloudflare Worker + D1，不使用 Mac SQLite，也不自动同步 Mac 存档。身份为服务端分配的 HttpOnly、SameSite Cookie，保留独立浏览器会话；不把自报身份头当作账号。Sites 的外层访问权限由平台控制；Worker 登录校验不代替外围分享配置。

旧 `farm_states` 和 `farm_commands` 表完整保留，新版本按同一浏览器标识一次性导入兼容数据。旧版羊毛保留 legacy 兑换权，姓名、关系、外观、习惯和回忆保留；不能映射的新旧奖励完整归档在 legacy 中，不凭空发新奖励。旧 `/api/farm` 返回 410，避免两套规则同时写同一份旧档。

D1 使用全局 CAS 提交门闩及原子 batch。采收扣减、访客入库、日限额、回执同批提交或回滚。无 Cookie 的首次 POST 只建立身份并返回 428，不执行业务；前端保留同一命令 ID 最多自动重试一次。首次身份确认前不轮询房间，避免迟到的 Set-Cookie 覆盖已加入房间的身份。

当前是可玩的协作演示，不是跨设备统一账户、全服排名或公网好友系统。AI 图像/视频服务仍未接通，错误和草稿状态不会伪造生成成功。

## 开发与验证

- Node >=24.9.0；`npm run install:ci` 安装锁定依赖。
- `npm test`：规则、真实模型、SSR 首屏、D1 原子事务、身份窗口及真实本地 workerd+D1 回归。
- `npm run typecheck`、`npm run lint`、`npm run build`。
- `npm run db:generate`：schema-only additive migration；发布工具应用 `.openai/drizzle`。
- `npm start -- --port 5191`：隔离 Worker 预览，不使用用户 Mac 的 5190。

导入的 Vite/Three.js 游戏代码使用原项目 TypeScript ESLint 策略；Sites 壳、API、适配器仍使用模板 Next 规则，避免把非 Next 游戏组件强行套成 React Compiler 组件。没有对新后端关闭 lint。

本地测试不等于线上或视觉验收。WebGL、实际触控与音乐听感未通过 Chrome 插件目视验收，不能据构建成功宣称已验收。发布后的源版本、API、模型与入口资源另行检查。
