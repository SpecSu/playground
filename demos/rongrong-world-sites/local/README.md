# 绒绒世界 · 完整本机演示运行包

这不是前端覆盖包：`dist` 为完整静态应用，`runtime/src`、`runtime/server` 是匹配的当前游戏与 Node 后端。`MANIFEST.json` 和 `SHA256SUMS` 记录准确源码与每个文件，包含 60 个真实 GLB，另有 1 个独立的金字塔内部 SPZ 空间。

## 入口与边界
- 沿用 `http://127.0.0.1:5190/?name=twx`（或原来使用的 localhost）；name 是公开演示选择器，不是认证。换浏览器 origin 会使用不同的浏览器存储，勿为升级改 origin。
- `?name=test` 是另一演示档；许愿池仍在原本机命名空间内。正式线上数据不会复制到本机。
- 不带 name 保留原本机匿名模式，账号 API 明确 503，不伪造正式登录。
- 真人寄养只在在线牧场使用，面板固定链接到官方首页；本机接口拒绝正式寄养。
- 月球五个 DIY 伙伴只在样例串门临时互动、成长，离岛重置，不能带回家、出售或配对。
- 金币调试仅演示账号 +1万/+5万，不能流入正式账号；无真实货币。

3. Node 必须 >=24.9（原安装已验证24.22.1）；`runtime/node_modules` 仅链接到现有、版本核对一致的外部依赖目录：three0.186.1/react19.2.6/react-dom19.2.6/lucide-react1.31.0。不得复制用户DB或密钥进包，不重装共享依赖。

## 回滚边界
启动前可切回旧程序。新版产生自定义蛋/新字段之后，旧r3不是兼容的业务回滚：先停服务并保全最新命名库，优先前向修复。不得把旧DB备份覆盖新进度，也不得用旧后端继续写新格式。正式数据库与所有浏览器存档始终保留原样。

云端测试只证明所列CPU/HTTP/SQLite/DOM合同；实际Mac安装状态由安装负责人单独确认，不宣称移动GPU/浏览器视觉已验收。

包版本以 `MANIFEST.sourceCommit` 与 `SHA256SUMS` 为准。兼容静态目录中的历史 `farm-build.json` 不是当前包版本 authority；不要据它误判仍是旧前端。保留的旧哈希 JS/CSS 仅用于已打开的旧版本页签补载，不是旧后端回退。
