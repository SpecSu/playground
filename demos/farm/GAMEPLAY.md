# 绒绒农场 · 完整试玩版

目标：玩家以自己的 LX 分身走进农场，认识三只性格不同的小羊，亲眼看到「我的动作成为它的习惯，下次它认得我」。本轮在原分支完善本机版本；沿用 390×844 Feed、全屏场景和底部抽屉，不新增常驻侧栏。

## 完整循环与 P0

| 系统 | 具体玩法与完成边界 |
| --- | --- |
| 进入 | 新存档默认 LX；旧 v1 存档一次升级为 LX，玩家 ID、动物、关系、羊毛、设施均保留。以后主动换外观会保存，不强制覆盖。 |
| 走动与选中 | 原版摇杆/WASD/点地移动；点击/轻触羊身或名字打开该羊卡片。拖拽、取消、多指、摇杆手势不触发动物卡；被前景遮挡的模型不穿透拾取。 |
| 动物卡 | 名字、个性、实时状态、亲密阶段、三个动作习惯、最近记忆、普通/星点外观；切换三只羊、互动、关闭返回场景。 |
| 个性 | 皮皮快靠近并跟拍；茉茉先动耳朵后小幅回应，保留距离；豆豆等自己的节拍并改编。不被亲密度抹平。 |
| 动作学习 | 舞蹈/蹦跳/喜欢。全局回应冷却 6 秒，同动作至少隔 12 秒记住一次，三次为观察→模仿→邀请。每项最多三次成长。 |
| 喂草 | 从牧场摘青草喂指定羊，无付费/饥饿惩罚。模型实际低头咀嚼并显示青草；每羊间隔 45 秒，前三次各 +1 关系，之后只陪伴不刷分。 |
| 陪伴 | 指定羊一起待 20 秒，靠近玩家、出现计时；完成后手动记下。完成/取消绑定原会话ID，旧重试不能结算新会话。刷新结束未完成活动，超过 60 秒不结算；不扣关系。每羊间隔 5 分钟，前三次各 +1。 |
| 守护者 | 奶蛙是独立 NPC，可点开守护者卡。带一次群体节奏，30 秒冷却，留下共同经历。LX 始终是玩家实体。 |
| 记忆/复访 | 实际刷新或明确「演示快进 6 小时」后，用真实保存的习惯欢迎；无习惯不伪造。快进已开启时不能重复领取同次快进。 |
| 奇趣外观 | 舞蹈习惯达到邀请 + 奶蛙共同事件，显示小星点预兆；可选择保留或恢复普通，不丢个性、名字、关系。规则驱动原型。 |
| 羊毛与设施 | 自然 30 分钟 1 团，上限 12；领取后推进结算时间。8 团换软垫舞台，实体出现且解锁舞台蹦跳。无离线惩罚、无亲密产量倍率。 |
| 相处手账 | 八个有限目标及羊毛奖励：认识三羊1、首次喂草1、全体跳舞1、完成陪伴1、学会舞步2、奶蛙合拍1、记得你1、搭好舞台1。前七项能攒够8团搭舞台，不必等离线或使用快进。领取逐项落库且幂等。 |
| 保存/失败 | 本地 SQLite + 设备 Cookie 身份；命令收据防重。保存失败保留原命令并提供重试，禁止其他操作伪装成功；加载/资源失败有可见反馈。 |

试玩路径：LX进入 → 点三羊看卡 → 喂草 → 对大家跳舞 → 陪伴20秒 → 间隔跳三次形成习惯 → 奶蛙合拍 → 刷新认得你 → 领取手账羊毛 → 搭舞台/一起蹦 → 可逆星点卷毛。
