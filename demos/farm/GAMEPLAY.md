# 绒绒庄园 V5 · 本机可演示版本

本版本仍是原来的390×844竖屏Feed。玩家控制自己的LX；换分身只换外观，三只羊、守护者与玩家各有独立身份。目标是把一次照料、一次空间选择和一次创作，变成同一座能保存的小家。

这是V5蓝图的本地实现：真实规则与存档可运行；主题使用明确标注的预制模板，拜访和共创是明确标注的本地演示。没有接入实时AI或真实好友服务。

## 从进入到第一次复访

1. **先选守护者。** 狼已经在地图边界出现，选择期间危险冻结。选刀盾狗、喵脆角或奶蛙，事件使用同一张真实地图，羊预约床位、沿道路回棚、在门前排队。教学有保护兜底，不会永久失去动物。完成后点“伙伴守住了，去喂第一口奶”。
2. **点动物，喂第一口。** 点羊身或名字打开它自己的底部卡片，看到幼崽阶段、饱食、精力、亲密与下一成长条件。幼羊喝奶，少年/成年吃饲料。点主按钮后LX先走近，再完成3秒动作；完成时才扣1份。移动、取消、换对象不会把尚未完成的食物扣掉。
3. **认识性格。** 皮皮热情、回应快，茉茉慢热、先动耳朵再小幅模仿，豆豆有主见、会改编节拍。跳舞、蹦跳、表达喜欢都能看出差异；亲密增长不会把三只变成同一性格。
4. **走通生活区。** 摇杆、WASD/方向键或点地移动。圈养区、草场、池岸、家园工作台连续相通，相机跟随LX。羊与LX不能穿设施或走入水域。工作台免费补食物；背包最多3份。第一次分别喂过三只+8材料，走到草场/池岸/家园+8，第一次合法布置+12，各只结算一次。
5. **把小家变成喜欢的样子。** 底部“+”打开布置；“主题”里先预览晴日牧场、荷叶村或星空小窝，再确认应用，可恢复上个主题。场景配色和装饰真实变化，动物ID、关系、路径和棚位不变。
6. **做一次空间实验。** 点“看看大家怎么回家”，观察实际路线和门口排队。结束记录分别列首轮及时、入棚、受伤、救回、纪念，不把它们混为一个失败数字。再搬棚、加入口或缩短路径，重新演练比较。无损演练不刷材料。
7. **留下作品，再回来。** “作品”私有保存当前布局/主题、选入的真实事件、相机与可用时的实际场景缩略图。刷新保留身份、名字、习惯、位置、施工、守护事件和作品。已保存的习惯会产生迎接；没有学会的动作不会随机假装记得你。

## 照料、关系与成长分开算

| 维度 | 当前规则 |
| --- | --- |
| 需求 | 饱食/精力0–100，初始55/80。有效在线饱食每分钟-1，移动精力每分钟-1，安全床位精力每分钟+5。离线饱食整次最多-20且不低于30，精力可恢复；不因饥饿死亡。 |
| 喂养 | 预约→真实可达路径→1格内→3秒→扣1份并饱食+30。错误食物、满饱H≥80、取消、断路、重复请求都不会多扣。H≤70且距上次有效照料至少30真实分钟才记成长经历。 |
| 幼崽→少年 | 真实24小时，另需3次有效喂养、草场30在线秒探索、一次已预约床位连续60在线秒休息。缺哪项卡片会写明。 |
| 少年→成年 | 进入少年后再满72真实小时，另需6次有效喂养、两个不同会话探索、一次玩耍、两次安全休息。成年前不产日常材料。 |
| 亲密 | 0–19初识、20–49熟悉、50–79亲近、80–100默契。手动有效喂养+3每日最多2次，玩耍+2最多2次，共同探索+2最多1次，总上限12/UTC日；离线不扣关系。 |
| 习惯 | 同类动作在不同会话、不同UTC日逐步观察→模仿→主动邀请，最多记3次。同一天连点不能瞬间训练完；旧档已学会的习惯保留。 |
| 安全休息 | 先按实际路径预约共享棚位，走到真正入口并完成入棚服务后，才累计60秒。多开一门不会多出床位，站在棚旁不算。 |
| 奇趣外观 | 奶蛙合拍后可体验规则驱动星点卷毛；可恢复普通。它不是实时AI生成，也不增加战力。 |

自然档年龄从V5开始记录，旧版并没有年龄资料，因此不会把旧关系凭空换算成已成年。旧名字、个性、亲密阶段、已学习惯、实际经历和外观被迁移。旧羊毛、舞台与手账原记录保存在`legacy`归档及原`farms`表，没有换算或重复发成新材料。

**独立演示档**使用全新的演示动物ID、材料、作品和权限。年龄240倍，因此幼崽/少年的年龄门槛分别为6/18分钟；30分钟有效喂养间隔等照料条件仍按真实规则。不能声称24分钟必然成年，也不能把演示收益迁回自然档。

## 建造、拓荒与有限经济

初始12×12格、60材料、6份食物（手持3/工作台3）、赠送6容量保护棚、食槽和工作台。赠品的已付成本为0，拆除不能变材料。

| 项目 | 成本/占地/用途 |
| --- | --- |
| 保护棚 | 24材料，3×3，6共享床位，30在线秒建成 |
| 独立入口 | 8材料，独立排队，共享原棚容量 |
| 食槽 | 8材料，1×1，6份容量 |
| 道路 | 每格1材料，每格2在线秒 |
| 观察台 | 12材料，2×2，实际位置和视线适合时增强猫的观察 |
| 饲料厂 | 20材料，2×2，每档一座，每60秒3份，离线库存上限12 |
| 池岸坡道 | 10材料，1×2；不会让羊获得游泳能力 |
| 装饰 | 每件2材料，只改变允许的布置表达 |
| 拓荒 | 走到东侧X≥10勘察5在线秒，再花30材料/60在线秒增加相邻6×6 |

所有新建、搬迁、拆除、修路、加门、开关门先显示合法性、成本、路长、棚位和不可达原因。改造会检查占地、水域、动物当前位置、可达保护位、预算和布局版本。施工中的占地也会阻挡导航，已缓存路线会重算。事件尚未收好记录时不能改变布局。

同时只施工一项，确认才预留材料，完成才安装最终设施。免费搬迁耗10在线秒。取消只退本次预留一次；拆除返实付80%向下取整，赠品返0。蓝图撤销只恢复该布局变更，不回滚动物成长；不能通过撤销、拆除或取消叠加多退。

工作台每30在线秒免费准备3份基础食物。饲料厂生产与配送分开：LX每趟搬3份，装/卸各2秒，配送按实际路径1格/秒，最多两趟，食物进入目标食槽的6份真实容量；可再走到食槽装进背包。装不下的随身食物退回工厂，拆除食槽的存粮退回工作台，回工厂才结束。警报期间配送暂停，手上食物保留。成年动物每12真实小时产2材料，每只最多存6，领取推进原结算时间且防重；亲密不乘产量。

## 守护者与空间策略

只有一个主动槽。刀盾狗速度1.8、视距6，走到1格内最多拖一只狼6秒，同一狼不重复叠加，冷却20在线秒。猫速度2.2、视距8，实际在观察台位且有视线可增加4格；4格内归拢持续8秒，把普通2秒反应延迟降到0，冷却12秒。奶蛙速度1.2、视距5，半径4格安抚12秒消除惊慌停顿；泡泡将一狼移速减半4秒，最多贡献真实剩余行程2秒，和安抚共用施法锁。换岗在无事件时确认，准备20在线秒、间隔5在线分钟。日常可选择陪LX散步、在指定位置驻守或沿合法路线巡游，三种状态互不叠加。

警报来自实际视线与遮挡；动物按可达路径距离预约有限床位，稳定ID打破平局。门队列每只基础1秒，加惊慌停顿；多个入口分别排队但共享棚位。只有服务完成、真正占用预约床位才安全。首轮“及时”严格要求入棚时刻T早于狼到该门的W；相等只记暴露，不直接判死。

设计文档的双入口、密集单入口、缩短路线三组算例已由独立到达与队列公式测试复核：前两组猫/狗/蛙顺序会变化，缩短路线后都能改善。**这是明确假设的算术基准**；当前现场结果始终按本场动物数量、真实路线与能力范围计算，不硬写6/4/3。

文明6的借鉴落实为四种思考方式：

- **位置有后果**：设施真实占地，保护棚离动物远会多走路；观察台放在盲区不会自动早发现。
- **预算有机会成本**：同一笔材料可用于工厂、观察台、入口或拓荒；不能同时获得所有收益。
- **建设顺序可比较**：先改善现有回棚路线，或先扩地增加活动区，产生不同成本与风险面。
- **探索与当前视野分开**：勘察给出可扩展地块，发现狼仍依赖当时位置与视线。

这些是参考V5设计的策略启发。棚位、门队列、惊慌、奶蛙安抚、狼与追救是本作规则；不是复制文明6的数值、战斗或回合系统。本版没有科技/市政树、城市/外交、地形邻接产量或完整自动经营系统。

## 安心、挑战和中断

自然档与无损演练不会永久删除动物ID。攻击链有可见前摇：接近→2秒攻击前摇→受伤减速→4秒抓取→沿真实路线叼走；玩家/伙伴可打断，释放在实际地点，仍需护送。边界追救有180在线秒窗口，连续靠近3秒解救；后台、离线或断线不推进窗口。默认失败是可恢复走失，面板可免费找回。

真实永久损失只在**独立演示档**主动选参与名单、勾选后果、再次确认后开启。名单外、守护者和只读访客不承担永久损失。失败保留原ID与名字作纪念，不复制一个同ID动物冒充复活；自然档原朋友完全独立。

世界状态、事件种子/位置/阶段、施工和待执行行动保存到本机SQLite。命令与收据同一事务，重试沿用原ID；过期会话、旧任务取消、重复领取/购买/提案接受都不能作用于新任务或重复结算。离线仅结算受限需求/产出，在线行动不会因一次大时间跳跃而瞬间完成。

## 创作与本地拜访的可用边界

- 主题：三个官方预制模板，真实场景预览、确认、版本和恢复。
- 蓝图：允许的组件/区域/预算/基础版本；重新核对占地、路、棚位与成本后原子施工，可部分接受。过期/撤权/旧版本/非法方案拒绝；撤销不能多退材料或回滚关系。
- 私有作品：当前场景、相机、实际可用的缩略图与真实事件记录。保存不发布。
- 示例庄园与本地访客：明确标注的只读分身投影，沿合法路线走访、留记录；不是联网好友。
- 本地帮助：每访客/主人/UTC日1份，主人跨访客每日最多接受2份，48小时到期；合适目标H≤70时只补H30，不替主人加亲密或成长照料。拒绝/到期/撤权按收据退一次。
- 共创：主人选区域、预算、允许操作及帮助/Remix权限，访客只提交提案，主人接受才动世界。查看/编辑授权不包含公开授权。

真实生成、账号与朋友图谱、跨设备授权/快照后端、审核/配额服务、公开发布、联网多人尚未接入。没有秘密/付费API或固定关键词伪装AI。具体适配接口与阻塞见V5_INTEGRATION.md。
