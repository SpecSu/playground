## 已落地

在原有 390×844 Feed 的场景卡与折叠背包中升级物资管理，没有创建新的全屏页面。

- 新增 `src/v7/ResourceIcon.tsx`：手绘 SVG 羊毛团（五品质）、粮袋、奶瓶与叶片、食物袋、工厂、食槽、金币、羊箱、披风、旗面、路标、狗盾、签名、小羊、叶片、星星，以及可供后续建造引用的木材/石料图标。没有新增依赖或远程图标请求。
- 新增 `src/v7/InventoryPanel.tsx` 与 `inventory.css`：四列物资网格，全部/羊毛/补给/装备分组、名称、实际数量、空库存、明确选中勾选、详情与用途。羊毛品质同时有颜色、Ⅰ–Ⅴ等级、普通/优良/稀有/珍稀/典藏文字，不依赖色觉。
- `MarketPanel.tsx` 已直接嵌入统一背包，保留已有收取、卖出、合成、旧货兑换与来源、购买羊箱、承载预览/过期检查、取消与孵化流程。金币、生产粮与已买羊箱也使用同一图标语言。
- `WorkshopPanel.tsx` 的配方与成品显示对应披风/旗/盾等物件轮廓；原来的单字小羊/字符叶片/字符星星选择器改为 SVG，成品仍保留真实纹样缩略图。
- `FarmCyclePanel.tsx` 的生产摘要与循环提示使用实际羊毛图标。
- `EstateView.tsx` 原有背包入口也接至同一组件，保留折叠入口与收毛按钮。

## 操作与真实性

- 羊毛数量只读 warehouse，待收获产物不冒充入库库存。
- 新版逐份出售明确发送 v7/v6 来源，蓝/红/金仍先提示配方损失；旧版按原权利独立兑换，不一键全卖。
- 合成仍调用 `v7-synthesize`，读取现有价格与库存，不在 UI 结算。
- 付费生产粮与随身/工作台/工厂/食槽免费照料食物分账展示。购买粮食、工作台补粮、工厂配送、食槽装粮均发送现有真实命令；配送使用实际食槽 ID，空库存/满携带量/执行中等状态禁用对应操作。
- 已制作且未拆解的作品来自 workshop.items。披风装卸、狗盾驻守装卸通过现有 workshop 合同，携带真实 workshopVersion 和 worldVersion。盾在活动威胁期间禁装卸；旗面与路标通过现有工作坊放置流程，不假装直接摆放完成。
- 所有数量与装配状态等待权威快照更新，不本地扣款、发物资或显示虚假成功。相同快照有同帧重复提交锁。
- 现有存档无木材/石料库存，未创建这两类库存或伪造数字；木石 SVG 仅是可复用视觉资源。
