# V15 · 幼崽慢慢长大

更新时间：2026-10-24。沿用现有 390×844 牧场、孵化演出和动物小卡，不新增成长管理面板。

## 玩家流程

买蛋 → 放在空地孵化 → 出生就是幼崽 → 约 1 分钟成为少年 → 再约 1 分钟成年。点动物走近后，小卡显示当前阶段与距离下一阶段的时间；成年后只显示“已长大”，不再倒计时。每一段之间持续平滑变大，不是在时间点突然换尺寸。

## 当前机制

| 项目 | 当前规则 |
| --- | --- |
| 新生动物阶段 | 出生至 60 秒：幼崽；60–120 秒：少年；120 秒起：成年 |
| 时间含义 | 每个成长阶段约 1 分钟；共约 2 分钟到成年，不是 1 分钟成年，也不是成年后再等一轮 |
| 阶段与体型 | 阶段按年龄统一推进；个体的出生、少年、成年目标尺寸在蛋中一次确定，彼此可能明显不同 |
| 尺寸约束 | 每只动物自身始终满足幼崽 ≤ 少年 ≤ 成年；不会因为换阶段重新随机而变小 |
| 平滑过渡 | 使用两段平滑插值；在 60 秒边界连续，成年后停止增大 |
| 个体差异 | 出生尺寸约 0.60–0.95 倍；成年尺寸约 0.90–2.20 倍。数值是技术边界，不显示为动物大小标签 |
| 物种 | 羊、猪、兔与真正的 Blender 骨骼牛共用同一成长规则；模型制作方式不影响成长时间 |
| 卡片反馈 | “幼崽 / 少年 / 成年”阶段标记；未成年时显示细进度条及到下一阶段的秒数；成年显示“已长大” |
| 演出与镜头 | 保留原孵化动画；成长不弹新窗口、不重复破壳、不重置镜头、不打断举起或走动 |
| 其他玩法 | 购买、出售价格、孵化 10–15 秒、每日繁育次数与概率不变；新生动物到 120 秒后才取得成年配对资格 |

“随机”表示不同个体的成长潜力不同，不是每秒抽一次尺寸，也不是每换阶段重抽。大的幼崽不必比所有小体型成年动物都小；保证的是同一只动物只长大、不缩小。原有 `size` 分类仍用于既定价格与分布，不用它替代成长阶段。保留 `normal / large / giant` 三个内部价格档，出售分别为 40 / 65 / 100 金币；成年个体尺寸分别在 0.90–1.30 / 1.30–1.80 / 1.80–2.20 倍内随机，不因成长追加价格或收益。

## 存档与兼容

- 继续使用当前浏览器的 `dreamina-egg-farm-v2` 存档，不覆盖旧模式存档，不自动重置牧场。
- 新蛋保存 `growth` 成长曲线；孵化复制给动物。刷新、重新进入或离线返回都不重抽个体尺寸。升级前尚未孵化的蛋，会在孵化时按稳定种子生成曲线。
- 年龄由出生时间和已保存的最大成长年龄共同决定。离线回来直接显示应有阶段与尺寸，不补播错过的阶段庆祝；时钟回拨不能让已经保存的成长倒退。
- 已经存在、没有新成长曲线的旧动物保留原体型曲线与原 60 秒成年资格，不突然缩回幼崽。旧动物的阶段显示对应原进度：0–30 秒幼崽、30–60 秒少年、60 秒起成年。新增动物才使用完整 0/60/120 秒节奏。
- 成长不额外生成蛋、金币或奖励；离线成长不意味着离线配对。

## 验证范围

`minimal-growth-ui.test.ts` 直接挂载真实 React 小卡，检查 0、59,999、60,000、119,999、120,000 和 120,001 毫秒边界的阶段、倒计时、进度条，以及离线重进后没有重复弹窗或假倒计时；还验证旧动物保留 60 秒成年、新生稀有动物不会被误称为已经巨大。`minimal-world-growth.test.ts` 使用真实场景与骨骼牛检查四个物种的阶段边界连续、成年尺寸封顶，以及存档更新间隔内时钟回拨也不缩小。规则测试覆盖连续尺寸、随机潜力、存档与兼容；`minimal-growth-geometry.test.ts` 检查实际变形网格与 LX 的接触；密集复核覆盖 0.60–1.00 倍间每 0.05 倍，以及 1.60/2.20 倍。幼崽被举起时收腿向外，不通过抬高根节点制造悬空；放下恢复原步态与着地。密集独立几何检查 114/114 通过。

DOM 测试不等同浏览器 WebGL 画面或真机触控验收。发布与本地部署状态以单独的验证记录为准；文档不替代线上资源及本机运行检查。
