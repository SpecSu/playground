# V8 动作与物资管理

## 范围与约束

基于 V7 开发分支 09e7d6ee213c10f5debd06761a70811030d3236f，保持原有 390×844 Feed、2.5D 相机、LX 分身和存档结构。用户已批准直接实现。此次在 dot 环境修改与验证，不启动用户的 Codex 执行任务，不改动其 Mac 正在运行的服务。视觉验收与部署状况以本轮验证报告为准。

## 实现次序

1. 先为喂养、眺望、两狼入场和背包操作新增失败测试，再实现。
2. 保留现有骨骼/程序几何，复用 IK 与局部姿态思想，避免把互动变成连续抖动。暂不制作外部动画片段或用视频代替实时操作。
3. 喂养按接近、面向、递食、进食、收回推进，保持原有一次性事务；移动和取消不能重复扣粮。
4. 高台采用独立守护者任务，必须沿可达入口登台，站稳后侦察生效，取消时安全下台，不锁住玩家移动。
5. 开场使用两只真实威胁单位、不同外围入口和错峰入场，避开羊与建筑；选守护者期间保持无损，跳过或刷新不重复结算。
6. 背包与市场共享图标体系和真实数据，展示名称、品质、数量、用途和操作。区分免费照料食物与生产粮；不虚构木石等不存在的库存。
7. 集成原有入口，验证重复点击、忙碌态、缺资源、取消、恢复与旧档兼容。对比最终代码与原始 Git blob，只发布实际变更，不删除未下载的资产。

## 验收底线

- 手、道具与羊头接触有明确时间轴；没有脚步时不原地踏步、没有技能时不跳舞。
- 观察台旁边不再等于站上台；进入、离开与侦察判定一致。
- 两狼不与羊同点出生；守护者选择等待不会伤害幼崽。
- 品质不能只依赖颜色，物资不能只用一个字或 emoji 代替图标。
- 背包操作接现有命令与服务端校验，不伪造成功、库存、联网或生成结果。
- 完整测试、类型检查、构建以及视觉验收分别报告，未执行项不能标记通过。
