## 文件与交付拆分
1. 跨日经济：herd-economy.ts、v6-production.ts、estate-cycle.ts、raid-cycle.ts。
   旧仓库和动物待领量在迁移时形成旧版批次，保留1/2/4/7/12兑换权；迁移只执行一次。
   新版最多6生产位，每12h每位2白，存6批；初始3位。新增/换位从完整周期起。全场一个稀有目标，蓝2/红6/金14周期；离线最多结算6周期；切换下周期生效。等级仅解锁方向，标签保留且暂停纯标签消费。
   批次含动物来源与经济版本；消费与退款按实际批次记账。
2. 制作规则：workshop.ts，独立测试。普通披风/旗面4材料+白1、路标8+绿1、狗盾16+蓝1、签名8+金1；白2加工绿1。
   一次首件普通试制权，成本0单独记录；狗盾只可在独立演示档借用。
   成品、图案资产、作者/事件来源、实付账本与版本持久保存；重复制作/拆解/解锁幂等；拆解材料80%向下取整、实际羊毛原批次全返；赠品不生料；永久签名不可拆回金毛。
   一个战术槽与独立披风/旗面外观槽；应用重新校验世界/工作坊版本，事件中不能换战术。
3. 狗盾：threat.ts + tactical-shield.ts及实际导航测试。预设锚点，狗可达且驻点；6s路障替代贴身拦截，不叠加等级延时。羊狼都不能穿越，狼能绕行；阻断暴露动物唯一撤离路时拒绝，等待本侧已预约动物过后再展开；事件中锁锚点。
4. 场景与界面：WorkshopPanel.tsx、workshop.css、world-workshop.ts、EstateView/App/World集成。
   “做披风→选图案→试穿→确认”短路径；草稿不扣料，预览可取消；确认后关闭小卡看场景。图案裁切/大小/色彩可编辑，实际披风挂在伙伴、旗放合法位置、卸装/换图/回退真实更新。
   生产位/稀有目标/旧库存兑换清晰分区，不恢复常驻经营仪表盘。
5. 生成与互动边界：查现有provider/auth源码后决定接入。未连接时保存真实失败/未连接任务状态、独立预算未知、模板回退；任何客户端不能声称审核通过或写入生成成功。
   真人好友未连则明确说明；本地示例不叫好友。补本地提案项目累计预算，不能两提案各花完整额度；不伪造真人接力。
