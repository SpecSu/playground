# 01｜一个世界，三种深度：不擅长经营，也能玩得好

<image source="notion-file-block://50da3195-0945-4f61-ad4c-4f228474a006/87f5c394-53fe-4cb1-8284-9efdce0d0f93?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=v6-01-hook-interface.png" />

<b>主爆点不是“我又抽到一件金装”，而是“这是我养的团团，朋友画的图案真的穿在刀盾狗身上、挂在它每天走过的小院里”。</b> 一段真实关系提供创作题材，物资给作品一个游戏内落点，朋友的贡献改变最终结果。别人可以走进来看，也能带着许可方案在自己家做一版。

<image source="notion-file-block://4e235c51-ed11-430b-a3f1-388216022540/bb024251-f064-4601-abe6-743991bb3a54?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=v6-02-living-loop.png" />

大众只需理解四个按钮：<b>给刀盾狗做披风 → 请AI或朋友画图案 → 试穿 → 确认制作 / 保存作品</b>。没材料可以预览、借用演练；不想生成就用等功能模板；没朋友就自己完成。进阶玩家才展开功能配方、地形和配装差异。

<b>选择与舍弃</b>：不选“AI随机换三套主题”作为主卖点，养成没有进入创作；不选“模型自由造技能”，无法保证数值与事实；不选“稀有物直接刷积分”，会把陪伴变套利。推荐把固定规则的制作方案与开放的视觉表达结合，先做一件真实可装配作品，再做有第二个真实作者的作品。

<b>什么证明它有爆点</b>：不是生成按钮点击，而是用户愿意把结果装上、隔天仍保留、能说出图案来自谁和哪件事。对外展示只能用真实截图 / 录像；没有发生过成功救援就拍散步或休息，不用AI生视频补造战绩。完整回放系统未接前，用已记录事件卡和实际截图，不宣称重现历史每一帧。

<b>产品中心不是“会规划的人赢”，而是“每个人都能养出关系、表达自己、被朋友看见”。</b> 好奇养成的人先看小动物，喜欢表达的人先换主题、拍故事，策略玩家展开地图和经营。三者使用同一身份、同一动物、同一庄园、同一好友关系，不做三套不相通的产品。

- <b>低门槛</b>：进入即有 LX、幼崽、已验证安全布局与守护者；不会安排就选“帮我安排”，不会创作就从好看的现成主题开始。
- <b>高上限</b>：愿意深入时，自行调整保护棚、食槽、道路、观察点与拓荒顺序；策略结果真实可解释，不靠隐形战力。
- <b>AI 原生</b>：不是贴一个“生成”按钮。创作结果要进入生活、成为好友遇见的内容，再形成作品与二创。
- <b>社交不胁迫</b>：单人能养大动物、建设和创作；不把拉好友、分享或点赞数量设为成长门槛。

<b>三个用户都成立</b>：每天两分钟摸摸喂喂，也能看它长大；只想拍好看的故事，也能有可应用的作品；想研究路线与预算，也有可验证的空间策略。

## 读法与完整玩法的边界

本轮在V5详细规则之上补齐资源去向、真实AI、作品接力与留存动机，不另开一个无关小游戏。快速理解可读每节大图；要讨论实现，展开“详细规则”。<b>下文所有自创数值均为试验参数，算例只有算术核对，尚未通过真实游戏仿真和平衡测试。</b> 文明6原版事实与本作原创分别标注，第04节有官方页码对照。

# 02｜第一次五分钟：先拥有一个小家，而不是先学一套系统

<image source="notion-file-block://7f161029-11cf-4f6f-9ab0-3fd88ac0f3b5/c46bee24-f8d1-424b-a7a3-4a547f3b9b99?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=v4-02-first-five.png" />

<b>狼袭开场仍保留，但它是情境选择，不是新手考试。</b> LX 来到庄园，看见幼崽缩在围栏里；刀盾狗、喵脆角、奶蛙各有短动作预览。可以自己选，也可接受推荐；选择期间冻结危险。第一次操作只教“点伙伴守住入口”或“关上侧门”，慢了有伙伴兜底，三位都能通过教学。

狼退走，幼崽冒出“饿了”；点击卡片只有一个强主按钮：“喂奶”或对应物种的“喂食”。LX 走近、拿出食物、幼崽吃下，反馈落实到动作与成长记录，不弹一屏规则。

接下来用一句话或现成主题表达“我的小家”：例如“荷叶村”“星空小窝”。先预览，不强迫提交图片、登录社交或等待生成。结果未完成时继续散步；跳过 AI 也能完整玩下去。第一次离开可以保存一张“第一次回家”，<b>保存不等于公开发布</b>。

<b>新手只需要知道三件事</b>：它现在要什么；我下一步能做什么；我的创作放在哪里。路径、预算、视线、门宽等内容先隐藏在“看更多 / 自己规划”里。

## 从0分钟到第一次复访，完整走一遍

<image source="notion-file-block://74d51c71-bd71-422c-a7ef-aa9d77bb6e04/af390aba-c048-466f-aff9-9adedc5c35d0?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=v5-01-session.png" />

<toggle>
详细规则｜第一局每一步输入、结算与下一决定

<b>0:00–0:40，选守护者。</b> 狼出现在围栏外，幼崽有明确受惊表现。玩家点击狗 / 猫 / 蛙的短预览，看到“擅长什么、做不到什么”，不看战力总分。选择期间威胁暂停。确认后只引导一种操作：狗守入口、猫带幼崽走侧路、蛙在集合点安抚。教学均有容错，慢操作不会失去动物。

<b>0:40–5:00，认识并照顾三只幼崽。</b> 卡片默认突出“喂奶”，LX逐只走近完成；三只不同反应：慢热先闻、好奇绕一下、贪玩追空奶瓶。有效照料不因动作长短变得不公平。首次分别喂到3只，结算一次“第一顿”里程碑 +8材料。背包空时主按钮变“去工作台补充”，不会消失成灰按钮。可命名，不命名保留默认名。

<b>5:00–10:00，走通生活区。</b> 随LX从圈养区到草场、池岸和工作台，镜头连续跟随；通过3个区域的指定路标后，一次性 +8材料。草场散步成为幼崽成长经历；池岸只是可体验的风景，羊不能因此获得水中行动。玩家可以中途拍照，任务进度保存。

<b>10:00–15:00，第一次创作与改造。</b> “荷叶村”生成可以在后台进行；玩家先试现成主题。移动食槽预览显示回棚路径与占用，确认一份合法布局，记录一次“布置小家” +12材料。免费搬动已有设施也算，不要求先花材料赚奖励。累计教学奖励28，初始60未花费时最多有88；三个事件ID只结算一次。

<b>15:00–25:00，无损演练。</b> 默认问“想看看大家怎么回家吗？”接受才启动，拒绝不锁成长。显示路线而非先显示公式；一只羊在门口慢了，结尾说明“门前排队较长，可以把食槽挪近或增加入口”。演练不扣动物、不产可重复刷的材料，也不等于真实风险挑战。玩家按一次推荐，预览方案，确认后再演练一次看差别。

<b>25:00–30:00，形成可带走的成果。</b> 应用已审核的主题、拍第一张故事照；可选开放好友快照或访问示例庄园。未完成生成留在任务栏，退出不丢任务。此时自然档的动物仍是幼崽，绝不把“体验完整”写成30分钟已成年。

<b>第一次复访。</b> 先看一件实际变化：年龄进度、已完成的生成、被接受的朋友帮助之一；再给一个行动。未满24小时不宣布升少年；满24小时但缺休息，写“还差一次安稳休息”。错过一天不清亲密、不补算狼袭。

演示档可以240倍加速年龄：幼崽6分钟、少年18分钟，仍要完成里程碑。它是单独测试存档，不能把24分钟养成的动物、材料、作品授权或奖励迁回正式账号。
</toggle>

# 03｜养成与空间仍然扎实：从幼崽开始，点得懂、走得到

<image source="notion-file-block://795d5228-2043-4e4a-aa99-06dc13f360ca/51771e88-7c07-499e-993c-f094d1fc45de?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=04-growth.png" />

成长、性格、亲密与外观继续分开：幼崽逐渐变大、活动范围增加；基础性格稳定影响行为；亲密来自相处质量；AI 换外观不重置名字、记忆和关系。同一只慢热羊换上星空配色，还是那只慢热羊，不会变成新的高战力宠物。

<image source="notion-file-block://2679f61f-3eba-4fd5-97ea-0a1b357afe48/5214e7c0-2a81-4d68-9043-67285089f933?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=06-animal-card.png" />

<b>卡片与喂养是大众体验的核心，不是工程附属。</b>

- 点动物只弹出不遮挡动物、道路和移动操作的底部小卡，展示名字、阶段、眼前需求；默认一个主行动和两个次行动，下一成长条件与真实记忆可主动展开查看。选定动作后小卡立即收起，回到场景观看LX走近与动物反应；不以半屏弹层挡住喂养和移动。
- 幼羊喂奶，少年羊吃适配饲料；幼鸭使用幼鸭粮与安全饮水，不套用羊的奶瓶模板。
- 点“喂食”后自动走近再执行；错误食物、吃饱、路径不可达要说明原因，不扣错物品。移动或换目标可以取消待执行动作。
- 有效照料、休息、探索构成成长里程碑；连续满饱投喂不刷亲密。到时间但缺条件，写“还差一次草场散步”，不让玩家猜。
- 基础食物始终有免费兜底，生成额度不足、朋友没来、忘记上线都不会让幼崽无法继续养育。成年仍能学小习惯、主动邀请，不只是产出机器。

<image source="notion-file-block://e97b79d9-dcf1-44f3-8e9c-22f758b896b5/002bf44d-63bf-4fe8-88d9-cb1253be62d7?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=08-camera.png" />

<b>仍是同一张连续地图</b>：圈养区、散养草场、浅水池岸、家园工作台通过道路连接；LX 可用摇杆 / WASD / 点击地面行走，相机跟随 LX，不跟着随机跑远的守护者。羊留在岸上、鸭通过坡道下浅水；门、路、容量与导航一致。卡位救援只修复技术问题，不能用来绕过挑战结果。

保留此前三 Demo 的 <b>390 × 844 竖屏 Feed</b> 比例、顶部状态与底部交互，不突然改成经营后台。这里的图是机制示意，不要求游戏场景变成文档平面配色。

<b>亲密的价值</b>：初识愿意接受照料，熟悉后会跟随、记住地点，亲近后主动招呼，默契时出现独特互动。人物动作可以形成习惯，例如好奇羊模仿 LX 挥手、贪玩羊追球；不再用难懂的“合拍”统称。MBTI 至多是可选趣味标签，不是隐藏战力或人格优劣。

## 从按钮到行为的详细结算

<image source="notion-file-block://e46c402e-499a-4bc2-8cc5-bc03bde9ed50/6bca851c-27a0-44ee-b5d8-8692eaee71e8?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=v5-02-care.png" />

<toggle>
详细规则｜需求、成长、性格与亲密如何彼此独立

<b>需求只先做两项可见数值。</b> 饱食H、精力E各0–100，初始H=55、E=80；H按有效在线每分钟下降1，离线每次最多下降20且不低于30，饥饿本身不导致死亡。走动中E每在线分钟下降1，安全休息每分钟恢复5；离线休息可恢复至100。低于30才强提示，不把每个轻微变化都推送给玩家。自动巡游也要能自行回窝休息，不制造持续红点。

<b>喂食事务</b>：点击→检查适配食物 / 有效目标 / 可达路径→预约1份但不扣→LX到1格内→3秒动作完成→一次扣1份、H+30且封顶100→记录事件。中途取消、目标已被另一事务喂饱、网络重试或路径失败均不多扣。H≥80时提示“已经吃饱，想玩一会儿”，不靠过量投喂刷奖励。H≤70且距离该动物上一次有效喂养至少30分钟，才计为一条成长照料经历；70＜H＜80可补充但不刷成长。

## 装备的功能和外观，必须分别验收

<image source="notion-file-block://983ff935-6cf1-4bda-bb45-d52f3985f05f/37ed067f-d5aa-492f-b699-b9de8b540294?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=v6-04-equipment.png" />

只保留<b>1个战术槽 + 独立外观槽</b>。普通披风、纹样和付费生成不能给同规则装备加战力。当前伙伴Lv1→2→3的24/48材料升级和入口16/32升级可暂保留封顶基础进步；不继续无限加等级，更不能让稀有度、装备、付费生成再乘法叠加。下面战术先按Lv1同条件验证，之后才讨论与封顶等级的组合。

<toggle>
详细规则｜横向战术、免费试用与退款账

<b>狗的折翼拦路盾，P0只验证这一件</b>：将原贴身拦截替换成预先指定锚点的6秒实体路障，不能在原拦截6秒上再加6秒。狗必须驻点，羊和狼都不能穿过，狼可沿真实替代道路绕行。只有本侧已预约撤离动物通过后才能自动展开；若会封死任一仍暴露动物的唯一撤离路，则禁止展开并标红。它用“改变通行位置”换掉“移动贴身拦截”，不是绝对更好。挑战中不可临时拖动锚点或换装绕过锁定。

<b>猫的诱导铃，P1待验证</b>：把单条来袭的临时目标引向一个可达空侧点，猫需驻点维持；不传送狼，不全场停狼。放错位置可能把威胁带向另一群动物。需要目标选择、脱离与优先级规则先验证，故不与狗盾同时挤入一期。

<b>蛙的叶幕帐，P1待验证</b>：从主棚预约容量中借2床给2×2格临近帐篷，例如主棚6→4、帐篷0→2，总容量仍6。蛙驻守不能巡逻；必须有真实通路与受影响动物的安全重新分配。不能从已占用 / 已预约床位强行抽走容量，不做无条件容量+2。

<b>试用与拆解</b>：预演借用免费且无掉落；正式换装免费；拆解狗盾退材料12+蓝1，猫铃退19+蓝1+红1，蛙帐退19+蓝2+红1，材料按实付80%向下取整、稀有料按实付全返，且成品必须销毁。赠品实付0，不返出资源；重复请求通过同一交易ID去重。试错成本落在少量普通料，不让玩家因唯一红毛不可逆而永远不敢花。

签名纹样是永久解锁，以账号+配方/动物签名ID唯一记账，已拥有就显示“已解锁”，不再扣金毛；重复换贴免费。不能既保留永久权益又拆出金毛。重新生成只查生成预算，不重收解锁料。取消制作前不扣毛，应用事务失败全部回滚；视觉版本回退不回滚库存账本。

<b>建设槽与撤销</b>：同时施工1项；道路每格2秒、小设施10秒、棚30秒、拓荒60秒，只消耗在线建设时间。确认时保留预算，施工完成才成为可通行建筑；施工区不能堵住现有唯一出口。取消未完成项目返还这次保留材料，事件ID只结算一次。已经建成的自购物件可和平期拆除，退已付材料的80%向下取整；免费赠送物退0。布局编辑未应用时撤销完全无成本；应用后的搬迁不造新物、免费且耗10秒，挑战锁定期间禁止改变碰撞/路线/入口。保留版本不等于允许反复回滚领退款。

<b>三个发展方向可混搭</b>：集中式优先中心棚和短路，省照护但占好草场；分区式先小棚与支路，缩短当地撤离但多付建筑成本；湿地式先坡道与池岸生活区，解锁鸭的行为和创作题材，但岸桥形成瓶颈。没有一条路线被设为数值总优解。

相邻地块先显示轮廓，LX到边界勘察点停留5秒后揭示地形、可达口与材料预览；无材料也可勘察。购买要求：与已拥有地块共享边、预算足够、存在合法连接口。购买本身不要求已有额外动物；<b>迁入新动物</b>才要求适配活动区、可达食槽和可用保护位。一次开36格，逐步扩展而非换房间加载另一世界。挑战事件进行中锁定拓荒与布局变更。

默认辅助可做：按既有预算上限补工作台批次；把现有食物送到已授权食槽；提醒休息；报警后按同规则指挥当前守护者与预约回棚。它不能：新建高价设施、挪走用户作品、花生成额度、替用户发表、开启风险、复制资源、跳过门队列。用户确认一个模板只授权这次应用，不是永久允许AI重建庄园。暂停辅助后，已开始的幂等事务结束或安全取消；不把离线时间算作托管失败。

# 05｜AI要生成能用的作品，不只是给按钮换名字

<image source="notion-file-block://d594a4f2-5499-41e8-af9e-4f47feb20dee/8f444bfc-97e7-4fd7-98b1-c14616bff10c?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=v6-05-ai-two-layers.png" />

<b>当前可验证的是3套免费主题预览、版本应用与撤销，没有真实模型任务、生成预算或动态故事。</b> V6不是把这三个选项叫“AI”，而是补一条真实内容进入游戏的通路。包装名可叫“共织工坊”，玩家看到的仍是“给刀盾狗做披风 / 请朋友画图案 / 试穿 / 保存作品”，不增加共织币、灵感币或回声币。

<b>AI在表达层真正创作</b>：输入团团的指定形象特征、1–2条已发生事件、主人意图和小林授权的小图，产出此前不存在的主纹样，再由主人裁切、缩放、调色。第一期只接盾徽 / 披风胸章与庭院旗面两类合格槽位，用同一张主纹样保持一致；完整披风模型、挂点和动作兼容仍需资产验收，不能把现有角色资产误当已支持任意衣服。

<b>功能层保持确定</b>：AI可以后续提出“用哪个已登记配方、设施放哪里”的结构化建议，不能创造无限护盾、任意床位、掉率、库存或战绩。第一期布局先由人拖放＋现有校验完成，不把AI自动规划偷偷列为首版前提。普通旗面、安静小院同样能成作品，不要求胜利回放或伙伴装备参与。

<toggle>
详细规则｜从真实输入到装配，以及失败时怎样继续

输入界面仅带入被选择的动物身份、允许展示的形象、指定真实事件和许可素材。原始相册、聊天、全量私密记忆不自动送给模型。动物ID与关系不因生成改变；故事的事实字段来自事件记录，修辞可以生成，不伪称朋友救过没见过的羊。

流程：选配方与槽位→模板或AI→显示独立生成预算→排队→生成→输入/输出审核→掩模与资产适配→可编辑预览→主人确认制作→扣游戏材料并保存资产→实际装配。成功任务返回持久资产ID，不拿临时下载链接当永久作品。材料可以预留，但必须明确显示且可释放；正式制作前不最终扣毛。

生成/审核/适配失败：释放预留材料，不消费羊毛，保留旧世界，切到等功能官方纹样继续。调用服务可能已产生成本，这是平台预算问题，不能拿羊毛当失败费；生成额度返还规则必须事先说明、按任务ID补偿一次。审美不满意可保留草稿或使用模板，不许无限免费重抽；普通预览可试不等于模型推理无限免费。

确认时重新校验最新预算、权限、槽位和世界版本；跨版本冲突需重新预览，不静默覆盖。库存扣除、成品生成、配方权益和作品来源一起幂等结算。网络重复回调不复制装备，不同时保留成品与全额退款。AI服务离线时，已有作品、官方款、照料、制作、布置与演练照常可用。

所谓“AI价值”必须可证伪：与可用模板同规则比较，若生成后不愿装、不想保留、次日没再用，说明表达价值没有成立；不以调用次数证明成功。
</toggle>

## 与即梦主营创作链路的连接

<b>庄园负责给创作真实素材和使用场景，即梦负责扩展表达；不是庄园产币给生成服务套利。</b> 从庄园点“继续创作”时，拟交接角色参考、用户选定事件摘要、主纹样、可编辑分镜草稿、署名与授权范围。接到即梦已有创作入口的具体API、账号权益和回流协议须另行验证，<b>当前项目没有接通</b>。

第一阶段可先用真实事件卡＋实际截图形成素材包；没有完整历史快照时不承诺重建过去的救援镜头。真实录像可剪辑，AI可润色字幕和分镜，不补造成功战绩。即梦完成的图片/视频经主人选择可回到作品墙、相册或剧情卡；只有另经网格/骨骼/碰撞/性能校验的资产才能回流成可玩的3D物件。缺官方接口时明确显示“导出素材继续创作”，不能假装已经端到端同步。

<b>不加新操作负担</b>：普通用户只选“保留团团的卷耳，想要星空感觉”；愿意精修的人在即梦继续改图、分镜和视频。修改后的内容作为新版本回到同一作品，不清空动物关系、不自动重画旧作品、不替用户公开发布。

# 06｜串门要看到作品在生活，不只是一次点赞

<image source="notion-file-block://966204ec-f51e-41a5-b2ee-a92271938c8a/fedb85cd-d8cd-41f7-948c-7dc9d11dadc5?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=v4-06-visiting.png" />

当前固定访客ABC、示例庄园固定路标、挥手/合影事件，都是本地模拟；合影目前没有真实双人图片，访客不是真实联网身份。作品接力不能建立在“把ABC换成好友名字”之上，必须补账号、权限、跨账户提案与持久作品。

<b>先保留三种实际值得做的访问</b>：走一段主人设计的生活路线；看这只动物的新阶段与作品被使用的变化；给一件具体作品贡献图案或局部改动。访问的是主人授权的版本与区域，不读全部私密事件。主人改版后提示“你上次来看的是v2，现在v3”，形成具体回访理由。

<b>轻帮助是辅助，不是核心留存</b>：日1/主人日2、48小时过期、饱食+30且不加主人亲密/照料的限制可以沿用，但当前访客只有初始1份、没有补货，所以“日1上限”并不等于长期每日能送。先落实真实账户与免费食物来源，再做跨日帮助；不发稀有料、不按朋友数量增产，不靠小号给模型费用补贴。

详细规则｜访问、帮助、收益和无好友体验

访问需主人确认可见范围：作品、指定区域、哪些动物资料、能否合照。访客带自己的LX/伙伴外观投影，不带走真实资产、不参加对方不可逆风险。实时多人未接前，明确是异步访问授权快照，不能生成“主人当时和你一起玩”的虚构历史。

有限帮助沿用每个访客对同一主人每庄园日1提案、主人每庄园日最多接受2次、48小时过期；庄园日界线固定，换时区不刷新额度。接受时重新检查目标、H≤70、食物适配与日限，成功H+30；不增加主人亲密和手动照料里程碑。吃饱改为礼物篮待用，库存与退还用同一事务记账。拒绝/过期按原来源返还一次，不能重复取出；访客初始食物耗尽后要走明确补充路径，不能无中生有。

朋友留下“你已授权公开的团团照片+我改的这一面旗”，主人回访可以看到来源与实际采纳情况；访客得到署名、被允许的收藏与制作方案使用权，不凭空得到成品、金毛或模型额度。各自制作要用自家材料；参与人数不会改变强度和产出。

没有朋友也能用官方模板和自己的旧作品完成同样核心养成、配方和表现场景。系统角色只能标示例，不伪装真实用户；不强迫分享、不以邀请数开成长门槛。拉黑/关闭互动立刻停止新邀请和未接受写入，留言和素材审核不通过不进入动物长期记忆。
</toggle>

详细规则｜累计预算、失败退款、撤权和版本冲突

# 08｜UGC / AIGC 发布与 Remix：表达有出处，共创有归属

<image source="notion-file-block://dbf18002-e635-4fad-9aa7-468579fa2d69/b3053770-3ca5-41d9-a2be-bbe4c8fc358f?space_id=f95e748e-bfbd-41ff-a2fc-bb7ca6b75018&name=v4-08-remix.png" />

本节是目标权限规则，当前作品记录并不等于已接公开发布或完整恢复快照。发布对象分清楚：<b>一段庄园影片、一套主题外观、一份可编辑蓝图、一则成长故事</b>。默认草稿仅自己可见；发布时选择好友可见或公开，展示具体包含哪些素材与人物。分享作品不等于开放整个庄园、访问记录和私密关系。

Remix 路径：选择明确允许二创的作品 → 复制授权组件到自己的草稿 → 修改 / 生成 → 规则校验 → 预览确认 → 署名发布。保留原作、二创与贡献链；只迁移内容组件，不迁移原动物身份、亲密、库存或未公开数据。

<b>产品规则建议</b>

- 用户应提供自有或获授权素材；涉及他人肖像、声音和好友分身，单独确认使用与公开范围。默认不提供真人声音克隆。
- 观看、编辑、公开、允许二创分开选择；“公开可看”不自动等于“允许二创”。允许私用和允许再次发布也区分。
- 发布前进行内容安全与权利提示；高风险争议进入人工复核 / 举报处理，不能声称自动审核能识别全部侵权。
- 生成草稿、导入蓝图、图片文字都作为不可信输入，不能指挥系统越权或绕过校验。
- 下架后停止新增分发与后续复制，历史衍生作品的处理范围明确告知；不作无法兑现的全网删除保证。
- 小朋友、普通用户、策略高手不靠相互卷数值争曝光；作品评价以表达、可体验性与创意为主，发布和分享始终可选。

<toggle>
详细规则｜作品的四种发布形态与许可检查

<b>影片 / 照片</b>：冻结拍摄构图与场景版本，发布前可隐藏好友分身、名字和位置标签；不自动附带私密提示词。<br /><b>主题包</b>：只包含已通过审核、可授权的贴图与预制组件设置，不含活体数据和私人参考原图。<br /><b>蓝图</b>：保存相对位置、适配地形、建议预算与必要设施；导入别人庄园时重新算导航与费用，不保证原布局适合所有地形。<br /><b>成长故事</b>：以真实事件和用户编辑为事实底稿，想象对白标为故事化表达；不给朋友编造未做过的行为。

发布流程为保存草稿→选择作品类型→检查包含的数据与来源→受众范围→允许仅观看 / 私用二创 / 再发布二创→预览确认。把公开开关和二创开关拆开，不用一次“确定”包办所有传播权限。

原作下架后停止新复制；既有二创按照发布时的许可与平台处理规则显示来源状态，必要时冻结有争议素材并人工处理。不承诺撤回能删除所有外部下载。P0先支持预制授权素材与自己的作品，复杂第三方权益争议不让模型独自裁决。
</toggle>

详细规则｜发现、预约、撤离、门队列与三个可复核算例

<b>发现</b>：威胁沿合法边界路径进入，不在动物脚下突然生成。单位视距内且无遮挡才发现；已勘察地形不等于看见当前狼。第一次有效发现记d并发全局警报，猫台位良好可更早发现，盲区时优势消失。告警标出方向、受影响群体和推荐动作，不直接给所有角色同样30秒倒计时。

<b>选择保护位</b>：警报时优先按可达路径距离分配空位，距离相同以稳定ID打破平局，锁定预约，避免所有动物冲向同一个最后空位。中途棚不可达才换备用棚。安全条件是进入合法棚并占用预约位，不是站在棚边就安全；保护总容量不因多开一门增加。

<b>出发与行走</b>：普通反应r=2秒，猫有效归拢可降到0。撤离速度v=1格/秒，受伤后0.7；每只动物的路径L独立计算。能避开可见狼的合法路线优先，但不能为了安全穿墙或跳深水。LX可抱1只幼崽，抱起3秒、携带速度1.5格/秒，同时不能配送；不可因此一次搬走全群。

<b>队列</b>：普通单门基础服务1秒/只，惊慌额外停顿p普通=1，高密惊慌=2，冷静=0。高密指本次事件同入口预约5只以上且受到狼嚎，事件开始锁定惊慌档，避免通过改队列瞬间刷状态；奶蛙只在有效范围/持续期内清除停顿。双门独立队列但共享棚位。一般算法：第i只出门时刻=max(该只到达时间,前一只完成时间)+本只服务时间。只有同时到达、同长路时才简化为d+r+L/v+n×(1+p)。

<b>比较口径</b>：狼到同一个门外交汇点的时刻为W；严格T＜W才计“首轮及时入棚”。等于W记为暴露，不直接判死；后面还有攻击前摇、场内救援与追踪救援。狗在来得及站定的一个口令该条狼路线W+6。

详细规则｜普通事件调度、攻击、追救与真实损失

<b>调度建议</b>：教学结束且完成第一次照料后，先有20分钟在线安全期；之后每5分钟做一次20%资格检查，每在线小时最多2次普通事件。它是待测节奏，不意味着每20分钟一定袭击。默认事件仍只产生可恢复后果；主动真实风险挑战由玩家点选，独立明确名单和场景，不把普通随机事件偷偷升级。

发生前检查是否有可达的预警与操作机会；没有就先给足迹 / 演练提示，不发动不可逆袭击。扩张主要增加边界、路径和盲区，不采用“每买一块地固定多打一场”的惩罚。单狼为首版，双入口双狼只作为进阶挑战 / 固定测试种子，不伪称P0日常已经实现。

<b>攻击链</b>：狼接近暴露动物至1格→2秒可见攻击前摇→未被打断则受伤、速度降到0.7→再次接触后4秒持续抓取→未被打断则叼走。受伤不扣全体亲密，狼不能一次攻击直接删除动物。狗阻挡、LX驱赶或有效泡泡可以中断；同次攻击结果以事件ID去重。

<b>场内追救</b>：狼叼着动物沿可见路线撤向边界，携带速度0.7格/秒；地图箭头显示出口。LX / 伙伴可追上打断；打断后动物留在实际位置，需再护送回棚，不能瞬间判定安全。释放与重新抓取均要遵守状态前摇，避免来回一帧切换。

<b>边界外救援</b>：出现邻近救援点，180秒在线可操作窗口；进入加载与说明阶段暂停，真正可移动后才走时。用已有移动和伙伴分散注意接近1格内，连续3秒解救；回到合法出口记成功，不新造复杂战斗副本。被赶开只损失时间，窗口到0或玩家二次确认放弃才结束。

<b>默认安心</b>：危险链只到可恢复受伤 / 走失；窗口失败后出现免费找回与照料步骤，不永久失去。<b>主动风险</b>：仅名单内自己的动物可在救援失败 / 明确放弃后永久失去，保留纪念而不返同一ID；名单外、守护者和访客投影受保护。故事与外观奖励不出售强度，不卖付费复活。真实损失是待用户确认的推荐分层，不假称最终已定规则。

<b>暂停恢复</b>：后台、断线、离线不新生事件，不推进攻击/救援窗口；回来恢复相同种子、位置、状态和已结算结果。退出不回滚损失，不复制奖励。模式不能在正在结算的挑战中被静默切回安心抹账；可以暂停，主动退出应先说明如何保存当前状态。若系统故障导致不可操作，走技术恢复与日志核查，不把技术错误当玩家失败。

<b>结束反馈</b>：只解释事实，例如“发现晚6秒 / 远端多走4格 / 门前5只排队”，给一项具体改造建议。及时入棚数、受伤数、场内救回数、最终失去数分开显示，不能用一个红色失败数字混为一谈。

详细规则｜哪些数据AI可提议，哪些只能规则引擎写

内容记录包含ownerID、assetID、来源许可、输入参考、模型/提示版本、审核状态、生成配额事务、可用槽位；不直接带可执行世界权限。蓝图提案只有允许组件和参数，不运行用户上传脚本。

首版优先固定角色骨架和碰撞、官方动作库、受约束图像/装饰槽。自由3D需额外验拓扑、骨骼、LOD、材质、端侧性能、动作适配与权利，不用“生成成功”代替“可玩成功”。新资产未通过验证，最多作为私有概念图，不进入真实导航、伤害或公开互动场景。

验收｜用失败条件判断是否真的融合

1. 真实AI输出能被审核、持久保存并装到一个合格槽位；模板只是回退，不能作为模型调用成功证据。生成失败羊毛扣除=0。

3. 三套库存选择余额与图中一致；每次拆解不超过实付，赠品不生材料，签名解锁不能反复退金毛。旧库存迁移可对账。
4. 产出记录明确“份”与“批”；6生产位全场最多24白/日，3位12白；稀有进度每全场自然周期最多1次，重复领取/切换不刷进度，离线可一次结算已存周期。
5. 主人给项目8材料授权，两个提案不能累计花16；部分接受和版本冲突重验；操作日志能够说明谁改了什么。
6. 一位真实朋友的贡献真的改变最终作品，主人能拒绝，访客不直接改存档、不拿稀有库存，公开与二创单独确认。
7. 普通用户5分钟看见一件自己的东西，3分钟可完成日常；不会策略、不生成、不邀请仍能养成。
8. 高稀有收藏不自动增加安心区袭击；挑战名单/离线暂停仍有效，真实风险只主动选择，玩法价值不靠无限战力或财富惩罚。
9. 有无AI、有没有朋友的差异看作品使用与满意度，不只看调用和分享按钮；未有足够真实观测前不声称持久留存已验证。
