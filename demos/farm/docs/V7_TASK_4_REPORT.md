价格与承载计算全部读取`V7_RULES`、`v7Summary`、`productionStatus`、`previewHatch`，不在UI结算或复制结算公式。稀有度直接决定产色，按动物展示真实产量/粮耗及停产原因；移除V6全场稀有目标和6生产位限制。保留最多6批/离线最多6周期说明。旧待领数量亦可领取。
