# V12 · 从一颗蛋开始

本版替代 V11 的自动礼物收益：领开园金币 → 去实体商店买随机蛋 → 放在空地孵化 → 留养/配对，或举去商店出售 → 再买蛋、开辟风景。

## 直接操作
1. 初次只出现领取 120 金币，不摆管理面板。
2. 点两格商店，LX 走近后买 30 金币的随机蛋。
3. 进入放蛋模式：可放格有绿框，非法位置给红色反馈；可以取消，蛋仍在袋子里。
4. 到期点蛋：裂壳、动物弹出、落地回弹。揭晓物种、性别和标准/大号/巨大体型。
5. 点动物走近，举过头顶；带到商店后看到动物及价格，再确认出售。不会点击商店就直接卖掉。

## 已实现规则
| 项目 | 本轮演示 |
| --- | --- |
| 开园金币 | 120，只能领取一次 |
| 商店 | 初始16格中的(0,0)、(1,0)两格；不能穿过、放蛋或改造 |
| 随机蛋 | 30金币；羊、猪、牛、兔各25%；购买时固定结果，孵化前隐藏 |
| 体型 | 标准70%、大号25%、巨大5%，无极小体型 |
| 性别 | 男/女各50% |
| 孵化 | 首颗10秒，之后15秒；演示加速 |
| 出售 | 标准40、大号65、巨大100；必须举着动物到店 |
| 成年 | 演示60秒；不代表正式版节奏 |
| 繁殖 | 玩家轻点配对，同种异性成年且靠近的动物，35%机会产该物种蛋 |
| 日上限 | UTC+8自然日，每只动物每天一次尝试，全牧场最多成功产一枚蛋；日期不加速 |
| 容量 | 动物与蛋合计最多16 |
| 地块 | 初始4×4；首只动物孵出后才开放相邻开辟40/格、改造20/次 |
| 防软锁 | 在店前，金币不足30且没有动物和蛋时可领取一枚起步蛋 |

出生结果、失败配对尝试和成功日上限都会保存，重载不能重抽。卖掉动物不删除发现图鉴。不自动离线配对，也不演出性行为，配对仅用爱心和靠近表达。

## 实际美术与反馈
- 实际 Three.js 模型已更换，不用概念图冒充游戏画面：四种独立动物造型、木质双格商店、蛋壳、自然地形。
- 放蛋绿框与悬停预览、非法红圈、连续走近、头顶搬运、出售金币、破壳弹出。
- 静态场景材质合批降低绘制对象数量，保留独立点击代理；不是已验证真机帧率。
- 场景几何与商店射线点选有专门测试；SVG辅助几何检查不等同 WebGL 材质/动画观感验收。
