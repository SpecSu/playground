# Dive Party · 海底潜水派对 (v1.0.0)

Dive Party 是一款基于 Three.js 开发的高品质海底潜水模拟捕鱼游戏。它深度整合了 Fish Party 的鱼类建模、材质、游动动画及 UGC 基因合成系统，并带来了全新的海底探索体验。

## 🌟 核心特性

-   **精美海底 3D 视觉**：多色珊瑚礁、动态海草、岩石细节、柔和体积光（God Rays）、多层深水雾化及海底粒子效果。
-   **流体化潜水员**：流畅的游泳动作、配备潜水面镜，支持自由角度瞄准与蓄力网弹捕鱼。
-   **生态化鱼群**：鱼群近身逃避反应、聚集提示（最佳撒网时机），深度越高稀有鱼出现概率越大。
-   **完整水族箱系统**：
    -   **3D 鱼缸预览**：在全屏水族馆中查看捕获的鱼获，支持环绕观察、缩放平移。
    -   **基因合成**：选择两条父本鱼，输入灵感 Prompt 或添加道具，通过 `synthesize` 系统创造全海唯一的「新物种」。
    -   **放生与回流**：放生的鱼会进入海底稀有池，可能在后续潜水中再次出现，形成数据闭环。
-   **独立本地存储**：使用 `dive-party-v1` 隔离存储，确保玩家进度独立。
-   **多端适配**：支持 PC（WASD/方向键/空格）及 移动端（虚拟摇杆/触控蓄力）操作。

## 🎮 操作说明

-   **移动**：键盘 **WASD** 或 **方向键**；手机端通过**左侧屏幕滑动**（虚拟摇杆）。
-   **捕鱼**：键盘 **空格** 或 点击**右下角按钮**按住蓄力，释放后朝移动方向发射捕鱼网。
-   **鱼缸**：点击左下角「**我的鱼缸**」进入 3D 预览与基因改造实验室。
-   **目标**：在氧气耗尽前探索深海。当氧气耗尽或手动浮出水面时，氧气将自动补满。
