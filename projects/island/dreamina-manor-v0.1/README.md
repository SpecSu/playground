## 玩法与结构

- 20 种植物（10 株原 GLB + 10 株程序化异植）、20 种程序化鱼，五档种子/鱼饵。每份只使用一次并产出一件；金色和巨型互斥，结果固定后刷新不重抽。旧植物身份、记录、售价与已排队随机序列兼容，不能用新目录排序重算旧产物。
- 买种、播种、生长、收获、拿放、售卖和自身建造在本地立即响应，再由持久日志分批提交云端；跨用户赠送/取走仍须云端确认。展示物不继续生产，可收回背包。
- 土地/码头/鱼缸采用真实 12 秒施工；已确认的 startedAt/readyAt 不随刷新或迟到回执重置。鱼缸按真实鱼包络、连续实心矩形及现版缸高规则容纳鱼，不靠任意压缩鱼体塞入不足空间。
- 自身施工/生长/钓鱼/待同步不会锁住串门；访客移动和原始跨岛操作须按各自岛屿和操作 ID 恢复。未知结果不能新建 ID 再扣一次费。
- 半屏分类面板、紧凑收获列表与鱼缸独立分组行，展示分组/数量出售、手持独立计数；分组只影响展示，不能合并真实物品 ID。首次背包默认收起。
- `app/`、`components/` 为页面与交互；`lib/game/` 为经济/状态/reducer；`lib/client/` 为日志与同步；`lib/server/` 为云端校验；`lib/art/`、`lib/world/`、`lib/avatars/` 为场景和资产适配；`public/assets/` 是运行资产；`art-source/` 是可编辑来源/脚本/许可；`tests/` 是正式测试。

网址 `uid` 是轻量庄园号，不是安全登录。知道同一庄园号的人也能使用同一进度；不要写入敏感信息，不把它作为正式账号鉴权或强反作弊方案。

## 部署边界

本目录是源码交接，不会自动发布。`.openai/hosting.json` 的原生产 project_id 已置空，数据库 binding 保留；另部署须按 `hosting.example.json` 配置自己的授权项目、数据库及环境。运行源码、锁文件、正式测试和素材与冻结 SHA 一致，只有 README/生产绑定配置以及新增交接材料存在 manifest 明示的归档差异。

Sites 发布包必须包含完整 `dist/`，尤其 `dist/.openai/drizzle/` 迁移、`dist/.openai/hosting.json` 和服务端，不是只上传 `dist/client`。原 public 站须沿用既有 Sites 项目与同一 DB，不能重建项目或用空库覆盖进度。浏览器音频需有效手势启动；云浏览器测试不等于手机实机或所有 GPU 通过。云 API/D1 长尾延迟仍可能发生，不宣称所有平台问题已根治。
