# 小岛视觉试验 v0.3 · 实施与验收记录

2026-10-23。本轮目标是验证拆分参考图 → 独立 Tripo 模型 → PBR → Three.js 装配的可行性；不增加玩法、经济或存档。工程从零独立建立，旧失败实验未覆盖。

## 已实际执行

八类独立资产全部完成几何、真实浏览器灰模检查、PBR 生成及装配。使用 v0.2 单块方形地块的相同副本组成 2×2 岛；每个单元自身没有十字沟。首批狗狗与树通过有限范围样板检查后才生成后续六类。

实际任务总成本 **380 积分**，完成后只读查询余额 **620 积分**。没有反复重抽。原始几何、原始纹理、展示版分别保存；详情见 `ASSET-MANIFEST.md` 与 `assets/manifest.json`。

几何使用 Tripo v3.1；纹理使用 v3.5-20260815，明确开启 PBR、高清纹理、原图对齐与去光照。去光照是生成参数，不等于保证贴图完全无阴影，仍需实际旋转光源检查。

## 画面证据与每轮主要修正

1. **round-01 / 单体灰模**：逐件看图。纠正狗狗、码头、灌木的整体朝向；发现狗狗长尾、树叶粘连、灌木针孔等限制。角色头、眼、耳和身体保留为整体，没有单独挪动。
2. **round-02 / 样板 PBR**：狗狗正面、中性光、反向光、竖屏；树暖阳。验证面部形态与材质可重新打光。将 4K 原纹理另制展示版，验证所有几何缓冲、UV 与拓扑不变。
3. **round-03 / 首次整岛**：灰模暴露树与角色比例失衡、码头过短、水面层次不足。缩小树、放大狗狗、校准甲板和水位，实例化复用岸石与鱼。`scene-partial-materials.jpg` 是着色器失败的排查图，不计为合格证据；`scene-motion-fixed.jpg` 记录恢复显示。
4. **round-04 / 用户反馈与光照**：按反馈检查狗狗尺寸、草丛落点、小船靠泊、岸石穿插。狗高改为 1.55m；灌木移入左前方单元并下沉根部；船体与码头保留间距；岸石移至岛外，仅保留贴岸接触。改为侧后方暖阳与冷色补光，减少泡沫带宽度，增加水下石与深度参照。
5. **round-05 / 完整纹理与最终检查**：八类模型均使用展示版 PBR；检查竖屏全景、植物近景、黄昏、侧面接地、缩放和旋转。最终截图以该目录为准，早期灰色灌木不是最终素材。

## 当前视觉约定

- 同一比例体系，Y 向上，朝前为 +Z；模型仅整体等比缩放与旋转。树 3.5m，狗 1.55m，灌木 0.95m，码头长 3m，船长 2.7m。尺寸是构图决定，不是对参考图的精确测量。
- 地块母件宽 2.55m，实际深度约 2.50m；逻辑拼接间距 2.48m，保留草沿轻微重叠。此生成母件并非制造级精确正方形；正式游戏模块化资产仍应手工规范边界。
- 甲板对齐来自面积最大的朝上水平面，避免误用柱顶；角色按地表射线接地。石头外移后保留自然贴岸，不能靠大片穿过草坪来藏接缝。
- 色彩管理统一为 sRGB 输出、Neutral tone mapping；一盏投影暖阳、冷色补光与低强度环境光。无 Bloom、景深或 SSAO 堆叠。
- 原 PBR 贴图保留。在场景运行时对绿色局部做高度色差、降低过强法线、设粗糙度下限；单体“原材质”检查仍能查看生成结果。
- 海水采用屏幕深度折射、深度吸收、降分辨率反射、动态焦散、地块与岸石/码头桩岸线泡沫。船舱区域屏蔽水面，避免全局水面穿过船舱。
- 微风是完整网格的极小连续弯曲，根部固定；鱼使用尾部顶点摆动和三个错相游动轨迹，船有轻微起伏。没有角色骨骼动画。

## 性能边界

共享网格与材质；水下岩石和鱼使用实例化；反射目标分辨率 45%、折射 70%，反射约 15Hz；阴影约 20Hz 更新，跨水体各遍复用；折射遍跳过干燥主体，最终遍跳过已经进入水体折射的水下物件；远离浅水与岸线时跳过相应焦散/泡沫的昂贵分支。DPR 有上限与持续低帧率自适应。

展示纹理：角色与树基础色 2K/法线与材质通道 1K；普通道具 1K/512；鱼 512/256。JPEG/PNG 仍会在 GPU 解压，因此这是尺寸及文件优化，**没有宣称完成 KTX2 GPU 压缩**。

桌面浏览器的小视口测试不能替代真实手机。真实 iPhone/Android、触屏双指与机身温升未测，不承诺所有手机 60 FPS。实际测量见 `PERFORMANCE.md`。

## 失败、恢复与未解决的差距

- CLI 0.7.2 本地参数校验不接受新纹理版本；未提交、未扣费。纹理改为官方 API。
- 灌木几何查询遇到连接中断，使用原 task_id 接续，未重生成。
- 微风 shader 出现负数拼接导致的编译错误，真实截图发现后修正；添加可见的 shader 错误提示，避免黑屏或缺件被当成完成。
- 灌木纹理首次下载包不完整，长度校验拒绝；再次查询相同成功任务并下载后通过，未额外计费。
- 狗狗尾巴比参考长；树叶部分粘连、纹理和叶脉还偏软；灌木少数叶片有小孔、背面稀疏。当前是可用的整岛视觉试验，**尚不能宣称达到原始参考图的最终美术质量**。提高最终近景品质的下一步应是定向网格清理，避免继续无目标重抽。
