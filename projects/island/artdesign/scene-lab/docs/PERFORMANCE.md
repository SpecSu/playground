# 性能与兼容性记录 · 2026-10-23

实测环境：本机 Codex 内置浏览器，完整八类资产与水体，390 × 844 CSS 竖屏视口，画布 390 × 797。每次预热 30 帧，再采样约 12 秒，测量期间固定渲染倍率。不是手机硬件测试。

| 条件 | 渲染倍率 | 平均 FPS | P95 帧耗时 | 最大绘制次数 | 最大三角面/帧（含离屏） |
|---|---:|---:|---:|---:|---:|
| 优化前 | 1.50 | 39.9 | 34.2 ms | 49 | 1,662,818 |
| 减少重复绘制后 | 1.50 | 46.1 | 33.5 ms | 41 | 1,290,562 |
| 交付预览档位 | 1.25 | 59.5 | 18.4 ms | 41 | 1,290,562 |

同倍率优化主要减少了重复绘制及水面无效计算；交付档位同时降低倍率，不能把全部帧率提升都归因于渲染代码优化。

八个原始 PBR GLB 合计 108.65 MiB，展示副本 14.05 MiB。纹理显存按 RGBA8 + mipmaps 估算约 106 MiB，另有阴影、反射、折射等缓冲；这不是实际 GPU 内存测量。未实施 KTX2，不能把 JPEG/PNG 的文件压缩率等同于显存压缩率。

本地加载由 HTTP 回环服务提供，不代表线上 CDN/移动网络下载速度。未模拟慢网或断网缓存。首次生成过程中遇到一次灌木文件不完整，文件长度校验拒绝后重新下载同一任务结果已通过。

实际浏览器检查包括：竖屏构图完整、横屏切换、拖动旋转与滚轮缩放、侧面接地、日光/黄昏切换。未测试真实触屏双指、iOS Safari、Android WebView、长时间温升或后台恢复；这些是后续真机验收项目，不能由本表推算。

代码/文件验证：10 项离线 API 防重复与格式检查通过；GLB 导入、整体比例、朝向、接点、共享实例与材质恢复检查通过；8 个展示版全部验证原始几何缓冲、UV、拓扑字节保持一致。
