# 01 · 参考图、拆解与资产确认

## 输入与美术方向

以场景主参考决定轮廓、构图、色彩关系与材质语言，输出一页 Art Direction。当前例子的视觉中心是树、角色、码头形成的层次；海水留白衬托主体。暖阳、柔和接触阴影、厚叶、圆润雕塑感要统一。移动竖屏优先，造型 > 流畅 > 数量，不增加玩法。

禁止用大量默认球/立方体堆砌来代替造型、混用写实和卡通素材、靠 Bloom/景深掩盖结构、通过删贴图假装完成材质重制。水体和灯光属于引擎工作；独特角色和复杂植物适合先生成独立模型，需要时交模型师修网格。Blender 是可选精修工具，本案例未用 Blender 建模。

## 拆分粒度

一类可独立变换、复用或验收的对象生成一份资产。本例为 dog/tree/ground/shrub/dock/boat/rock/fish。角色头、五官、耳、衣服和身体作为一个完整资产；码头结构作为完整单体。草簇、鱼竿仅保留参考候选，钓线适合引擎曲线。

**地块只有一个方形母件。** 四边、草皮顶面、土层与砂层由单体保证；相同单元在引擎中复制。不能将 2×2 场景图作为“单块地块”的生成输入，也不能靠非等比拉伸掩盖不规则接口。

## 图片制作

1. 先产出主场景方向图并确认风格；保存原图。
2. 每件生成干净主图：完整居中、轮廓清楚、背景简洁、柔和中性照明、很弱 AO、没有硬投影与彩色反光。
3. **标尺、文字、编号、尺寸另放规格表或 scale-layout.svg，不画进 Tripo 主输入。** 避免标尺被建成模型。
4. 必要时补侧面/背面。姿态、尺度、形状、饰品要一致；不能把“转头但身体背向”的图当正背视图。多视图没有一致性证据时，先只提交主图。
5. 保存生成工具、提示词、参考图路径/哈希、选中版本、淘汰原因；禁止覆盖唯一原件。

单张图无法确定背面、真实尺寸和拓扑。补充设计与测得事实分开记录。所谓无光照参考不是可直接贴到网格上的 PBR 通道；PBR 图必须基于确定的 UV 制作。

## 可复用提示词结构

```text
用途：图转 3D 的单体资产参考，不是场景或多格模型表。
主体：{一件完整对象，关键结构与相对比例}。
风格：统一的精致微缩雕塑；{形状语言、色板、材质}。
视角：{主三分之四/正面/侧面}，主体完整，边缘留白。
照明：中性柔和大面积光、极弱接触阴影，无方向性暖阳或彩色反射。
排除：文字、标尺、标签、拼图、重复对象、散件、裁切、背景场景、硬阴影。
一致性：{必须保持的五官、冠层、板梁、部件数量和颜色分区}。
```

实际完整提示词见 [PROMPTS.json](../art/v0.1/metadata/PROMPTS.json)，单方块见 [PROMPT.md](../art/v0.2/assets/ground/PROMPT.md)。这次移交不需要重新生成图片。

## 确认门槛

用 [资产规格模板](../templates/ASSET_SPEC.md) 写明尺寸是设计值还是测量值、正面/上方向、接点、水线、允许简化处、不能改变处。执行者按已授权任务完成看图确认；方向性选择确实缺失才向用户澄清，不把每个阶段机械地变成重复审批。

输入通过后再进入 3D。结构不清、关键部分遮挡、不同视角矛盾时先修图。两个真实淘汰案例见 [图片检查记录](../art/v0.1/docs/IMAGE_REVIEW.md)。
