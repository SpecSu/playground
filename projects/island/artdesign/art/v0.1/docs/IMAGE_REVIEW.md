# 图片检查记录 v0.1

> 本文文件路径均相对 `art/v0.1/`，不是相对本 docs 目录。

本包采用内置 image_gen 生成，依据用户原始场景图。共生成 16 张，保留 14 张（10 张主图、4 张补充视图），淘汰 2 张。所有生成图均逐张目视检查。它们是二维资产设计参考，不是 3D 模型、PBR 通道或浏览器渲染结果。

## 使用方式

1. 首批只试制 DOG 与 TREE。`tripo-pilot-inputs/` 内各放一张主图，分别提交两个单体任务，不把两张图当成同一个物体的多视图。
2. DOG 背图供模型师理解背部设计；若使用多视图生成，仍需检查返回模型的头身朝向、尾巴和衣服衔接。
3. TREE 补充图没有逐叶一致性，DOCK 侧图存在远侧绳圈差异；本版不将它们作为自动多视图输入。
4. BOAT 补充视图用于解释船尾与马达，尚未用 3D 重投影证明两图完全一致。默认先用主图。
5. 其余资产主图已准备，但批量 3D 生成应等首批样板通过。FISH、ROD、GRASS 也可用于轻量模型或程序化母件制作。

## 共同限制

- 所有图片含用于辨认体积的柔和明暗和少量接触阴影，不能直接当作无光照基础色贴图。
- 它们不是正交摄影测量数据；多视图的二维外观相似不等于三维对应成立。
- 细小连接、底面与不可见内部尚不确定。原图没有展示的背面、服装细节、尾巴和机械结构包含设计补充。
- 没有新增水体截图：原场景图继续作为水色与浪花参考，水体实现留在引擎阶段。
- 没有生成伪 PBR 通道；真正的基础色、法线、粗糙度等必须在确定 UV 的模型上制作。

提示词全文与每张图的生成输入记录保存在 `metadata/PROMPTS.json`。正式图片保持生成原件，没有程序抠图、重绘或拼接。
