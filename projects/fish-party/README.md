# 🎣 Fish Party · 果冻海钓鱼（v2.4.0）

纯 HTML + three.js r180，无构建步骤，所有依赖都在本地 `vendor/`（离线可跑）。

## 运行
ES Module 需要通过 http 打开（不能双击 file://）：
```bash
cd ~/Desktop/fish-aime
python3 -m http.server 5178
# 浏览器打开 http://localhost:5178        （?q=low / medium / high 指定画质）
```

## 部署（单文件）
线上网关只放行 `text/html`，`.js` / `.glb` / 字体等直接部署会被 403 拦截。所以部署前先打成一个 HTML：
```bash
python3 build/build_single.py   # → dist/index.html（esbuild 打包 JS · 角色 glb / 缩略图 / 字体 base64 内嵌）
```
只部署 `dist/` 目录。`dist/` 已加入 .gitignore，本地开发仍用上面的 http.server 直接跑源码。

## 渲染管线
- **海面** `src/water.js`：6 层 Gerstner 波（GPU/CPU 共用一份参数，船和浮漂精确随浪起伏）+ 极坐标 LOD 网格跟随相机 + 3 层程序化可平铺细节法线
  - 果冻感 = 浪峰透亮/浪谷深邃的体色 + 逆光次表面散射 + 体内焦散微光 + 弱化的菲涅尔
  - 粼粼 = 能量守恒 GGX 式高光 + 太阳反射带内随机闪烁的亮点
  - 船体周边泡沫与接触暗化、浮漂涟漪、实时阴影、远处空气透视与天际线无缝融合
- **天空** `src/sky.js`：程序化渐变 + 大气光晕 + FBM 体积感积云，同一份 GLSL 用于天空球、海面反射、PMREM 环境贴图 → 反射与天空严格一致
- **游艇** `src/boat.js`：参数化放样船体、柚木甲板（程序化木纹+凹凸）、清漆船壳、硬顶、不锈钢栏杆、软垫、灯串（黄昏点亮）、飘扬的旗子
- **角色** `src/characters.js`：圆润豆豆人比例 + 布料 sheen 材质；坐着喝饮料 / 跳舞 / 晒太阳 / 钓鱼等程序化 idle
- **后期** `src/main.js` + `src/grade.js`：HalfFloat MSAA → Bloom → ACES → 色差 / Lift-Gain / 饱和度 / 暗角 / 胶片颗粒
- **性能**：零外部贴图，全部程序化；3 档画质 + 开局 4 秒自动降档；阴影只覆盖游艇周边 20m

## 下一步路线图（建议）
1. **鱼类 UGC 管线（核心）**：玩家在 2D 画板画鱼 → 自动生成 3D（侧面轮廓挤出 + 鼓胀 + 骨骼摆尾 shader），或接入即梦生图 → 深度估计 → 网格化
2. **"盲盒感"钓鱼循环**：咬钩时的水下剪影预告、拉扯小游戏、出水慢镜头 + 镜头推近 + 鱼卡展示（作者署名 / 稀有度 / 点赞）
3. **怪东西池**：漂流瓶（玩家留言）、橡皮鸭、旧靴子、宝箱……同样支持 UGC
4. **多人**：好友同船（WebRTC / WebSocket），表情互动、合照模式
5. **美术打磨**：水下视角、水花粒子、浪尖白沫粒子、海豚跃出、夜晚荧光海

## v0.3 更新：钓鱼手感 + 大鱼 + 修复闪白

- **修复闪白/小白方块**：风格化 shader 的分阶处理只作用于漫反射，高光/光泽仍走物理 dotNL；粗糙度下限；toon/海面/天空输出统一 NaN/Inf 防护 + HDR 钳制，杜绝 Bloom 放大异常像素。
- **咬钩反馈**：1~3 次试探轻啄（浮漂点水+竿梢点头+音效）→ 真咬钩：浮漂猛沉、水花、震屏、红色「!」+ 倒计时环（浮漂出屏也贴边显示），0.5s 内扬竿 = 完美扬竿（起始距离更近）。
- **搏鱼**：按住收线 / 松手放线；张力条、距离与进度；鱼发力前 0.6s 预警（竿梢猛抖+提示）、发力时还按着会顶红断线，松太久鱼跑掉；鱼左右蛇行、水下鱼影、随机跃出水面；分段鱼竿按张力朝鱼的方向弯成弧线、渔轮转动。
- **出水 & 抱鱼**：慢动作出水 → 鱼翻腾飞向手中 → 角色 Holding 双手横抱在胸前、开心蹦跶，鱼阵发式扑腾（甩尾/拱身，角色被带得晃动）；镜头自动转到 3/4 正面「炫耀视角」，放生后回到原角度；朋友们欢呼气泡、彩纸、稀有度卡片（R / SR / SSR / UR + 投放者）。
- **大鱼**（`src/fishes.js`）：旗鱼、小鲨鱼、苏眉、翻车鱼、剑吻鲨、东星斑、红鲷、鮟鱇、锦鲤（占位：Quaternius Animated Fish，CC0，带游动/离水挣扎骨骼动画）。正式版 UGC 鱼只需提供 GLB 即可接入。调试可用 `?fish=Swordfish` 指定鱼种。
- **音效**（`src/sfx.js`）：WebAudio 程序化合成（抛竿、入水、轻啄、咬钩、扬竿、棘轮、水花、预警、断线、欢呼），零外部资源。
- **粒子**（`src/fx.js`）：InstancedMesh 对象池，水花/彩纸零 GC。

## ⚠️ 已知回归（改相关代码前必看）

这些 bug 修过不止一次又被改回来了。动到相关代码时先读这里，改完按「验证」走一遍。

1. **孵化前剧透：卵里出现最终鱼的样子**
   - 位置：`src/aquarium.js` → `addEgg()`
   - 规则：卵里**只能**放抽象胚胎（蠕动光核 + 绕行光点），**任何 kind 都不许**读 `egg.result` 去建模型 / 剪影。
   - 历史：v0.9.1 只给 `kind === 'synth'` 换成了胚胎，其他 kind 仍放剪影；v2.0 新增 `genemod`（基因改造卵）就又剧透了。v2.2 起所有 kind 统一走抽象胚胎。
   - 验证：基因改造 → 变成卵后，凑近看卵里不能看出鱼的轮廓 / 颜色 / 部件。

2. **不收线就能一直等下一条鱼（刷鱼）**
   - 位置：`src/angler.js` → `float / bite` 状态
   - 规则：真咬钩（bite）时没及时扬竿 = **鱼饵被吃掉**（`baitGone`），不能再等第二条，只能收空线重抛；重抛时海底鱼群会换一批。试探的大鱼（probe）、普通轻啄（nibble）不吃饵。
   - 验证：咬钩后不按，浮漂不会再动，按钮变「收线」，再抛一竿鱼群不同。
