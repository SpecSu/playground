Binding decisions: four demo hosts (Jiji anime, Kelly music, Bear toy design, LX tech/sport); old garden/source author IDs remain immutable. A separate display host can replace a visible character without rewriting provenance. User-selected selfie owner is Su Bei Ke (`human-subeike`). Final deadline 12:00 UTC; no worker publishing.

Clicking an actual live host approaches a reachable neighboring support, faces both actors and opens only **合影 / 送东西**. A nonce-bound selected-host lock is separate from ambient encounters. World changes, hidden page, close or a new gameplay command cancel stale arrival/photo/gift work and release host. No remote interaction or route teleport. Only this explicit two-character session pauses owner idle; ordinary camera/menu/editor browsing still permits semantic idle.

Gifts consume exactly one seed or one mature packed plant, explicitly chosen and sent to a named demo recipient. Before send: 本地赠送演示：扣除本机库存，不会送达或通知真实好友. Optional `giftLog` retains up to 60 complete item/provenance snapshots and permanent request receipts; cap/duplicate/recipient/maturity/quantity validation precedes deduction. No self, ground plant, building, currency or crystal gifts. Failed actions are atomic. Existing saves load checksum-first with raw head preserved; absent log is empty only in memory, no load write.

Own global terrain tone uses a small canonical preset enum in `settings.landPalette`, free and whole-island, including future land. Unknown legacy extra settings stay preserved and are ignored for rendering. Friends retain authored palettes; no per-cell editor.

Eight finite offline building samples: old three plus fluffy cat, anime collector, plush designer, two LX buildings. Same permanent blueprint/60 construction/20 relocation/50 demolition rules. Hobby/illustration sources have truthful text instead of invented photos. Plant and building creation dice fill supported text only, no immediate repeat and no submission/spend; parent-fixed remix excludes identical/incompatible output. Both editor text and placeholder are 16px.

Four approved offline Polaroid selfie PNGs are generated only after all four layouts are final. They are labeled fixed Su Bei Ke offline samples, not realtime current-avatar captures. Lazy same-origin image, stale decode cancellation, explicit PNG download; public build whitelist includes only final approved manifest references.

Photo viewing uses a photo-only contained ~72dvh tray capped inside safe viewport/dock bounds, fixed close/header and reserved Save PNG/status footer. Generic create/gift panels keep existing sizes. Preview-session URLs and accepted download URLs have independent lifetimes.
