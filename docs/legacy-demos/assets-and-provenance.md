## 角色和素材如何对应

当前 `public/avatars/cast-v1/manifest.json` 记录上传角色的 ID、显示名、来源文件名、尺寸与哈希。可选角色来自 `lib/club-avatar-catalog.ts` 及各玩法适配器；目录内旧GLB数量不能当作当前可选角色数量。新分身采用12个可选角色，另外包含DJ等角色资源。角色名称以清单与代码为准，本次未凭印象增添人物。

`public/avatars/manifest.json` 与 `scripts/avatars/README.md` 描述的是较早的程序化角色家族；其“代码原创、没有外部模型”声明**不能套用到当前上传的 cast-v1 全体模型**。旧生成器、运行骨骼适配、姿态检查脚本保留，禁止为了重新生成而直接覆盖已确认GLB。

云钓鱼保留20种海洋生物图鉴PNG及目录/几何逻辑；它们不是20个独立GLB。场景中的海洋生物、道具和动作逻辑还需要 `lib/fishing-*`、场景组件和相关脚本。火人节同样包含代码定义的装置与缩略图，并非仅靠图片构成空间。

## 可恢复与不可恢复

| 对象 | 本包包含 | 缺失或未验证部分 |
| --- | --- | --- |
| 前端与服务端 | TypeScript/React/Three.js、API、D1适配、schema、迁移、构建源与锁文件 | 不保证任意宿主可直接提供Sites身份与连接器服务 |
| 当前运行分身 | 原始发布GLB副本、角色清单、派生头像、运行与检查代码 | 上传GLB的原始Blender/建模项目、完整生成任务与全部输入未提供；不能宣称可从零精确再生成 |
| 旧程序化分身 | Python/Blender生成代码与历史manifest | 私人参考插画不在包中；不同Blender导出器可能产生不同字节 |
| 图鉴/装置预览 | 发布时使用的运行PNG与相应场景代码/脚本 | 原始高分辨率生成输入或所有设计过程不一定齐全 |
| 音乐/音效 | 播放用MP3、署名、处理参数/哈希及处理脚本 | 用户原始全长录音（未发布部分）、账户生成记录、完整商用授权证明未提供 |
| 数据与身份 | 数据结构、迁移、设备会话和共享状态代码 | 生产D1数据、玩家资料、收藏记录、Cookie、令牌及平台账户均不复制 |
| 视觉与性能 | 源码、运行资产、现有测试和本轮构建/HTTP结果 | 本轮未做浏览器、手机、听感、帧率或双真实设备体验验收 |

## 隐私处理

三个发布基线各有9张 `feed-ui/me-image*.png`（27份文件副本），含来源或公开授权不明的人像/个人主页图片。全部剔除，组件引用替换成新绘制的 `archive-placeholder.svg`；示例主页固定姓名改为“Demo 用户”。角色目录中用于历史模型映射的名字保留，未复制任何私人参考图或账户资料。

原运行素材不移动、不删除；清理只发生在新归档副本。原线上站点未改动。授权状态见 [第三方说明](../../THIRD_PARTY_NOTICES.md)，完整删改路径见 [archive-adjustments.json](../../manifests/legacy-demos/archive-adjustments.json)。
