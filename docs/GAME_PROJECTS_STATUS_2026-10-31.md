## 二 绒绒世界 我们做了什么

绒绒世界已从早期养羊、防狼和协作演示，发展为以 **3D 萌蛋牧场** 为主线的游戏：领取开园金币 → 买蛋 → 对应生态孵化 → 照料成长 → 繁育或出售 → 扩地并解锁更多生态。后续加入账号存档、许愿池交换、正式好友寄养、固定样例自定义蛋，以及月球、校园、金字塔等展示空间。

### 当前主牧场已接入

| 模块 | 已实现内容与条件 |
| --- | --- |
| 人物与交互 | LX 分身可点地走动，拖动转视角、滚轮／双指缩放；走近后照料、举放和买卖，动物、蛋、摆件、池塘岸线参与通行检查。误触保护、旧指令取消、模型失败重试已有实现。 |
| 买蛋与孵化 | 首次领 120 游戏金币，普通蛋 30 金币；草原、森林、湿地、沙漠、冰川五类生态蛋。首颗累计孵化 10 秒，后续 15 秒；地形不符或收回时暂停但保留进度，就绪后主动打开。 |
| 动物养成 | 普通规则目录有羊、猪、牛、兔、鸭、羊驼、企鹅 **7 个物种**；后两种须通过运行资源校验。幼崽→少年→成年，自主散步、吃草、喝水、休息；可打招呼、举起、携带、出售。 |
| 品质与繁育 | 白／绿／蓝／紫／金品质；同种成年异性可尝试繁育，成功率 35%，每只每天尝试一次、全牧场每天最多一枚蛋。成年伙伴回礼为全牧场每天一次 10 金币，不是每只每日领取。图鉴发现记录卖出后保留。 |
| 土地与氛围 | 10×10 范围、初始 4×4，支持相邻扩地、七种地形、三级土地照料、四种免费地表外观；供给可最多加快成长 20%。模拟天气、昼夜、音乐与环境声、音量和减少动态效果已接入。 |
| 云端状态 | 受信 ChatGPT 登录身份对应 D1 账号状态；持久指令、原请求 ID 重试、修订号与原子回执防止重复扣费。原浏览器档、正式账号、命名演示和本机数据库分别保留。 |
| 许愿池与寄养 | 有效账号间可异步交换普通蛋／动物、自定义蛋／伙伴、摆件；每天成功交换一次。真人寄养已有好友码、邀请、确认、取消、历史与结算，要求普通同种成年异性伙伴；双方确认后 5 分钟，成功率 35%。 |

这些是当前源码已接入的能力；账号、交换、寄养和部分模型仍依赖登录、D1、部署开关及资源校验，**不等于任意本地副本都可直接使用，更不等于本次已完成真人双账号验收**。图鉴附加观察记录仍含按 UID 隔离的浏览器账本，不应统称为全部跨设备同步。

### 可以玩但必须标为样例

**主题串门：**贝壳的沙丘绿洲、加新的冰川港湾、Rummons 的芦苇水乡、吉吉的月球剧场、咕咕的校园操场，共五个主题场景。姓名、头像、今日／本周热度都是示例展示，未绑定真人账号，不是通讯录或真实排行榜。普通样例可走动、打招呼、临时举放，不能带走动物或把样例收益转入正式牧场。

- **月球剧场：**肥嘟嘟、坤坤鸡、豆包、美羊羊、雨姐五个实际角色模型，有动作选择、表演、临时成长与照料。坤坤鸡可打篮球但不可举起；离岛后临时成长重置，角色不可出售、繁育或寄养。
- **校园操场：**八个独立骨架实例共用豆包慢跑模板，支持队形跑步、近处打招呼、全队暂停／继续；不能单人举起或转移资产。
- **金字塔：**在沙漠样例中按需进入独立 SPZ 内部空间，LX 第三人称行走；只开放检查过的中央走廊，侧室未开放，不能称作完整可碰撞建筑。
- **自定义蛋：**30 金币购买→填写名称和愿望→固定样例准备→15 秒孵化。便便小伙伴、许愿松树、月亮圆石、团团灌木四个模板已有真实状态流程。小伙伴可成长、举放、出售，但没有按任意提示实时生成新模型；其整体程序动作也不是新骨骼步态，暂不支持繁育。

素材实查为 **60 个 GLB 文件路径、去重 57 份模型，另有一个 SPZ 空间**。其中独立动作预览有 25 种动物、332 个动作，可播放、暂停、调速和看骨架；**不代表主牧场能养 25 种动物**，预览也不会替换正在养的伙伴。

### 暂停和未完成

当前默认牧场的防狼／守护开关为关闭；旧协作分支仍保留，但不能当成默认玩法。实时 AI 图像／3D／视频生成、提示词生成地皮、实时同屏多人、真人全服排行榜、自动联系人好友系统尚未完成；本机与 Sites 也没有自动合档。`?name=twx`／`?name=test` 只是命名演示选择器，线上仍需受信登录，并且不允许正式真人寄养。

### 已知边界

- URL 中的 `uid` 是轻量庄园号，不是安全登录；知道同一号的人可以使用同一进度。不能当作正式账号或强反作弊方案。
- 当前是固定目录、规则随机及 GLB／程序化模型，**不是运行时 AI 生成花园**。“怪梦花园”的 AI 变异、月光／音乐影响等设计提案不是这里的现成功能。
- NPC 岛与模拟收入不是真人玩家或真实账本；真实跨用户交易仍依赖云端。云 API／D1 长尾延迟、未知操作结果和未证明旧日志仍有处理边界，不能靠换请求 ID、清存档或盲目重发来恢复。
- 源码交接不附生产数据库、玩家存档、聊天或密钥；生产项目绑定已清空，克隆代码不会自动发布或取得原站控制权。

## 六 两个项目如何衔接

植物花园可供绒绒世界借鉴的是：点场景后自动靠近、操作立即反馈、永久图鉴、真实物品 ID、持久日志与幂等回执。**可借鉴不等于已移植。**动物有留养、成长与陪伴关系，不能直接照搬一次性种子经济、鱼缸容量或“取走他人成熟产物”；更不能让示例好友、样例收益和调试币流入正式账号。

下一次继续开发时，先选定项目和精确版本，再区分“补真实闭环”“扩演示内容”或“做新玩法”。这样可避免拿旧 GitHub 演示解释新线上版本，也避免把另一个项目的已实现功能误算到绒绒世界。
