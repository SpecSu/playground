# 人物面部修复与验证

本文前半部分记录 LX/吉吉历史供体修复。当前头饰验收见 `docs/audit/headwear/INDEPENDENT_REVIEW.md`；14 个实际 GLB 的当前哈希/成本见 `FINAL_ASSET_AUDIT.json`。

## 为什么替换

首版从夸张换装概念图生成整个人物，概念图与 3D 重建叠加造成面部身份偏移。用户明确不接受首版脸部；服装一致或通过自动测试不能代替相似度验收。

## 最终采用的路径

- 原始参考照片直接生成独立 3D 头部/胸像，不经过新的概念图改脸。
- 在私有工作目录裁掉胸像服装，保留头部的真实几何、UV 和派生纹理；使用已有 23 骨骼服装的 Head/Neck 权重承载。
- 每个人的三套衣服复用同一个规范头部，不分别生成三个不同的脸。
- LX：保留黑色矩形镜框与原照发型，清除裁剪残留的卫衣碎片。最新修订已移除旧黑色内领，清理下颈部锯齿裁切边界，新增与供体边缘位置及蒙皮权重一致的多环颈部连接，并将下端延伸、封闭在躯干内。真实面部、耳部与发型及原始派生纹理保留；银色大衣原有的衣摆权重修复继续保留。
- 吉吉：优先保留参考照的红发、大帽饰与张嘴表情；不是把照片贴在一个面片上。最新修订封闭头颈裁口，红发下缘保留相应颜色；小块发岛局部封口，内部共点使用一致蒙皮权重，避免运动时裂开。
- 完整原始照片和服务凭据不在 public、dist 或源代码包内。GLB 使用重建后的派生 UV 材质。当前分身创建流程按用户要求展示一张去元数据的 384px 本人照片裁剪预览（约17.3KB）；它是照片预览，不是3D渲染。换装缩略图才是实际3D模型渲染。

离线照片投射旧头网格曾作为后备实验。出现 UV 层删除导致的错位导出已隔离，不作为正式资源；只以最终 GLB 重新导入的渲染为验证证据。

## 性能与边界

高质量资源采用头部/身体各 2K 的基础色、法线与 ORM；估算 RGBA8 完整 mipmap 预算共 128 MiB。低配资源统一为 1K，估算 32 MiB。此估算不是 GPU 显存实测。始终只显示一个主角，沿用资源释放与服装缓存策略。

每套服装保留 dance_01、dance_03、dance_05 三个骨骼动画，不包含新面部表情骨骼或布料物理。头发、帽子可能在极端舞姿出现有限穿插，须以实际抽样渲染检查。单张照片重建不等于扫描级还原，仍须用户对本人相似度验收。

当前云浏览器没有可用 WebGL；自动测试、GLB 结构检查和 Blender 实际网格渲染不应被描述成手机实测帧率。

## 可复用脚本

- `head_transfer.py`：静态供体到目标 Head/Neck 的原型适配，支持保留动画。
- `crop_direct_lx_head.py`：本次 LX 供体专用的颈部/卫衣语义裁剪，不能盲用到其他人。
- `add_technical_collar.py`：历史黑色内领实验脚本，当前正式资源不再使用。
- `repair_neck_attachment.py`、`test_neck_attachment.py`：本次边缘清理、多环颈部连接及闭合/权重回归检查。
- `audit_runtime_skin.mjs`、`audit_runtime_skin_blender.py`：对同一 SHA-256 的真实 GLB 比较 Three.js 与 Blender 蒙皮位置，避免把离线结果误当浏览器 GPU 验收。
- `fit_source_jiji_head.py`：本次吉吉供体专用的帽饰/红发与人脸尺度适配。
- `reuse_canonical_head.py`：将已经检查的规范头部复用到其他服装。
- `optimize_glb.py`：只调整纹理，验证所有非图像 buffer view 字节不变。
- `render_character.py`、`inspect_animation.py`：从实际导出的 GLB 回读生成静态/舞姿验证图。

所有私有输入与生成过程记录仍在工程外，避免被静态网站意外发布。

## 历史 v2 颈部修订的验收证据

12 个正式高/低配 GLB 与独立验证的最终候选 SHA-256 一致；高低配几何、骨骼、动画及非图像 buffer 字节逐项相同。全部原有派生图像字节保持不变。六套服装的四个静态角度和三个舞蹈动作各三个相位、侧/后视图已制作并复核，证据见 `docs/audit/neck/`；独立跨引擎数值及发布目录哈希见 `docs/audit/final-runtime/` 与 `promoted-hashes.json`。

这些抽样检查未发现头部脱离或后颈空洞；不代表所有帧的布料/头发无穿插。旧衣领边缘的轻微锯齿及部分原有头发/肩部穿插仍可能在近景出现。真实 WebGL 浏览器渲染、GPU 内存与手机帧率尚未在本环境验证。

## 历史 v3 比例修订

在保留上一版颈部闭合的基础上，LX完整头部下移0.012模型单位（可见后颈约缩短五分之一），不压缩脸部；吉吉头部、帽饰和红发统一缩到88%，以原Head绑定中心为基准。连接网格逐圈过渡到底圈不动；正式高低配均已同步。原始派生纹理、身体服装、权重、骨骼、inverse-bind及三个动画保持不变。该版独立验收与历史哈希见 `docs/audit/proportions/INDEPENDENT_ACCEPTANCE.md`、`independent-assets.json`；旧 `docs/audit/ACCEPTANCE.md` 为v2历史证据。

## 当前头饰与第三位分身

吉吉仅红装保留修复后的红色帽饰；荧绿装改黑色/荧绿耳机，白金装改珍珠水晶发冠。保留此前88%头部比例、面部核心属性和闭合颈部；非红装只对上部红发尖端做局部衔接，不改变服装。头饰同材质批处理后的总绘制图元为5/10/9，实际GPU帧率未测。

第三位分身采用完整原生人体网格，不使用LX/吉吉的供体头拼接流程，不能套用CANONICAL头节点假设。基础造型为长袖黑T、白裤和皮鞋；另两套为同一人体的材质/小胸饰变体，而非重新生成不同人体。全6高低配结构和三个骨骼舞蹈可用；相似度仍由用户评价。新人物估算纹理预算为高配64MiB、低配16MiB，不是GPU实测。
