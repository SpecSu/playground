# 归档来源与差异

框架 0.1 整理日期 2026-10-23。来源为本会话用户授权的小岛美术实验；原项目代码快照 commit 29f10ad，分支 visual/tripo-v03。框架打包提交号见 Git 历史。

## 随仓库保存

- 原主参考、14 张保留资产图、2 张淘汰过程图、新版单块地块、尺寸说明、完整提示词。
- 八类资产每类五阶段 GLB：geometry/texture/display/runtime/compact，共 40 个模型文件，以及派生参数/哈希。
- Three.js 场景源码、vendor 与许可、当前布局、流水线/优化脚本、测试。
- 准备期、五轮视觉实施、减面/倒影、贴图压缩的真实截图与采样，包含失败/低帧率样本。

## 明确排除

原项目 .git 历史、AGENTS.md 中与本任务无关的私人规则、TRIPO_SETUP.md、tripo-env.sh、.env、账户/钥匙串配置、work/tripo 原始响应/上传 token/下载签名、临时处理文件、缓存、node_modules、虚拟环境、重复 ZIP。没有模型师 DCC/Blender 工程或骨骼动画文件，因为本例未制作这些文件。

## 相对源项目的改动

新增当前框架入口、skill、分阶段文档、交接模板、完整文件/资产清单与核验脚本；预览服务器增加 --port 参数以避免与现有 8771 冲突；API 缺凭据提示改为可移植说明；历史任务清单工具在缺失任务日志时停止，避免把历史账单写成 0。历史文档加历史标记，移除作者绝对路径与“本机服务已启动”的当前性表述。另新增移交副本浏览器截图及核验记录。原有图像与 GLB 内容保持原始字节；不重压缩证据图，不改变几何或贴图。

私有任务记录缺失意味着新电脑不能直接恢复原账户任务的全部运行状态。历史 task_id 与费用摘要可追溯，但需要该账户权限才能查询；样例运行和优化复现不依赖它们。

早期历史报告中的旧尺寸/余额/未生成状态、反射 15 Hz、模型未纳入 Git 等描述只适用于当时，不是本归档当前状态。当前默认 compact.glb，总 10.172 MB；全部五阶段备份的归档占用更大。
