# island/artdesign 的 agent 执行规则

本目录的目标是复用小岛美术资产搭建流程 0.1。先读 README.md、docs/HANDOFF.md，再按任务读取对应章节。SKILL.md 是简短路由入口。

- 当前规范以 docs/ 为准，旧 art/ 与 scene-lab/docs/ 是历史记录。不要把旧余额、旧尺寸、阶段暂停状态或历史命令当成当前事实。
- 运行示例、离线优化和查看素材不需要 Tripo。新付费生成仅在用户授权的范围/预算内执行；已有授权不重复询问。归档本身不授权后续无限生成。
- 默认保留原文件；按 geometry → texture → display → runtime → compact 产生派生版本。变更输入后旧验收结论失效，重新检查对应阶段。
- 角色作为完整资产整体缩放/旋转。不能分开挪头、眼、耳来修结构错误。水体与灯光不应掩盖造型失败。
- 单体输入不带文字、标尺、拼图、地面场景和强光影。比例说明独立保存。当前地块用 art/v0.2/assets/ground/primary.png；每个母件只有一个方格。
- 图像、灰模、PBR、场景分别验收；实际看图后记录。脚本能验证文件/哈希，不能替代审美判断。
- 新视觉构建默认至少三轮浏览器截图迭代，每轮处理影响最大的三个问题。若用户明确缩小范围或停止核对，执行该指令并标注未完成项，不能伪造通过。
- PNG/JPEG/WebP 文件体积、三角面、绘制调用、GPU 内存与 FPS 分开汇报。桌面竖屏不是手机实测；失败或异常样本也要保留。
- 不覆盖本包八资产样例来试新任务；在独立副本/分支中归档旧版本。样例的 work/tripo 不存在，不能据此声称原生成任务可自动续跑。
- 私密记录放 work/。不得提交 .env、Tripo profile、钥匙串导出、file_token、下载签名或账户原始响应。不要打印密钥，不把凭据发给 CDN。
- 最后交付可运行预览、真实证据、限制、资产清单与 Git 版本；用户只要交付时，不自行扩展新的优化任务。
