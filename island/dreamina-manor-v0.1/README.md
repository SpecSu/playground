## 体验内容
- 从 2×2 地块、24 贝壳币和 1 颗普通种子开始。点击空地走近后，用地上的小气泡选择种子种下；第一株从种下到成熟为 10 秒。成熟后点植物，角色走近收进背包。
- 每份种子或鱼饵只使用一次、得到一件产物。10 种植物、20 种鱼，五档内容，可出现巨型或金色。投放成功后结果和成熟时间固定，刷新不会重抽。
- 收获可以出售、拿在手里或摆放展示。展示物不再生产；随时能免费收回背包。
- 土地每格 60 币，可多选连通的一组新格后一次确认总价；码头每段 60 币，一段一钓位。新建/扩建等待真实 12 秒施工完成。
- 地上鱼缸首次占一块空地，80 币、10 条容量；之后每格 80 币、增加 10 条容量。旧两格鱼缸与已排队旧建造不缩小；相邻模块连为一个连续鱼缸。
- 点击朋友分身可赠送背包中的植物或鱼；只能在对方庄园现场取走成熟未收的植物或鱼。每个庄园号成功取走一次后，两类共用 6 小时等待。
- 真实访客的移动和聊天按数秒级同步；聊天输入时收起其他面板，自身发言立即显示在头顶，云端回执不会再弹一次，离岛或过时的未发消息丢弃；朋友列表读取真实登记关系及真实在线状态，不用固定演示庄园冒充真实好友。
- 单指拖动环绕、双指缩放；电脑可拖动/滚轮，也可用界面上的远近按钮。镜头平滑跟随角色，保留手动方向和缩放。
- 买种、播种、生长、收获、拿放、售卖和自身建造先在本机连续响应，操作日志再分批由云端核验。播种完成时间固定，迟到回执不会重置生长；跨用户赠送或取走仍需云端确认。断线操作保留原编号，不能重复扣费或领取。
- 鱼采用统一的观赏比例：保留不同物种及同种随机、巨型的大小差异，不以界面厘米数直接等比还原现实世界。大小记录与售价不会因展示比例调整而改变。

## 价格与等待
五档种子、鱼饵各为 8 / 28 / 90 / 250 / 700 币；植物通常等待 15 / 45 / 120 / 300 / 540 秒，第一株单独为 10 秒。鱼饵按同档基准的 70%–130%（上下界取整）固定随机一次等待，使用独立盐，不额外消耗产物随机序号。
只会获得所买档或幸运高一档。前四档升档概率为 5% / 6% / 7% / 8%，最高档不再升档；同档品种等概率。普通大小为本种标准大小的 80%–120%。巨型概率 6%、大小再乘 1.3；金色概率 2%、售价乘 2.5，两种变异互斥。巨型不重复叠加售价倍率。
商店可以查看实际商品详情。余额低于普通种子价格且没有种子或待收产物时，可领取一颗应急种子。

## 恢复、构建与发布
需要 Node.js 22.13 或更高版本。
1. 克隆仓库后进入 `island/dreamina-manor-v0.1/`；这是完整独立工程，不是分包或静态网页备份。
2. 执行 `npm ci` 安装锁定依赖，再运行 `node scripts/verify-archive.mjs` 核对源码与素材。
3. 执行 `npm test` 和 `npx tsc --noEmit`。全仓 `npm run lint` 仍有发布基线遗留问题，不等于已全绿。
4. 本地开发执行 `npm run dev -- --port 5174`。开发服务会初始化独立本地数据库。
5. `npm run build` 生成 Cloudflare Worker 和网页资源到 `dist/`。Sites 使用该构建产物及 `dist/.openai/drizzle/` 迁移创建独立 D1 数据库。
6. 本地生产预览需先应用本地迁移，再执行 `npm run start -- --port 5174`，沿用同一个 `.wrangler/state` 目录，具体命令见 HANDOFF。不要把本地 QA 数据上传到生产。

源码与锁文件在根目录，静态资源在 `public/assets/`，可复现 Blender 艺术源和生成脚本在 `art-source/`。艺术源不进入公开网页资源。
`.openai/hosting.json` 的 `project_id` 已置为 `null`，不会携带原生产项目绑定；本地构建仍可使用。另部署时按 `.openai/hosting.example.json` 在自己的授权环境配置项目与数据库。维护原线上庄园必须沿用原 Sites 项目及其数据库，不得重建、替换为旧小岛项目，或用空库覆盖用户进度。项目身份不等于凭据，归档不含任何生产访问密钥。

## 验证边界
开发检查点不是正式发布证明。移动尺寸测试为云端浏览器模拟，不等于真实 iPhone 或其他手机实机验收。海浪声音采用原钓鱼 Demo 的合成实现；浏览器需要有效手势才会开始播放。

## 连接恢复维护
已有进度的同步不重复创建存档；正常前台读取间隔约 2.5 秒，同岛在线心跳最多每 5 秒写入一次，15 秒在线有效期不变。切到后台后暂停轮询，返回前台先重新读取，再确认原操作；连接失败会逐步延长重试间隔。
未知结果的操作保留原请求编号和原正文，跨会话先核对旧 pending 与已写回执，不重新扣费或生成新交易。上述连接恢复机制不清档；最新版额外包含真实好友关系迁移，见 HANDOFF。若另一标签页仍有未确认的操作，请先回原标签页恢复连接，不要删除浏览器保存的数据。
服务日志仅记录固定错误分类、阶段、耗时范围与匿名关联号，不含庄园号、昵称、物品、聊天或请求正文。数据库间歇长尾仍需结合实际日志诊断，减负不等于证明所有平台故障消失。

## v7 本地响应更新
自身动作通过持久日志与共享 reducer 投影，确认前缀后只重放尚未确认的部分。随机产物由服务器预发序列固定，服务端逐项核验资源、依赖和时间；v6 未确认请求先按原编号与原正文恢复。聊天固定原始岛屿，错误岛屿的请求不会被转投。这些本地响应约束继续保留；v10 新增独立好友关系表，不改已有游戏资产数据。

## 大鱼空间与恢复维护
鱼保持原 ID、记录大小、售价及种内比例，手持与缸内使用同一尺度。放置要求实际模型包络能容纳的连续实心 N×M 矩形（可旋转），不能用散格、带洞区域或施工中的格子替代。1×1 净水高 2.6m，1×2/2×1 为 5.6m，更大完整矩形按现版空间模型提供深度；长窄缸低幅悬游，宽缸自由游动。

恢复实现与退场边界见 `docs/bounded-journal-recovery.md`；一次性恢复处理器不能改成通用任意存档上传入口，不能清除未确认本地原始备份。海面来源与许可见 `art-source/lagoon-reference/`。归档只含代码、必要素材及说明，不含真实玩家状态或私人恢复证据。
